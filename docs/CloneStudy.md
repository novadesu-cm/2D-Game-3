# ศึกษาด้วยการโคลน: เกมฟาร์มสไตล์ Roblox (ปลูก → เก็บ → ขาย)

> ไฟล์: `prototype/clone-garden.html` (หน้าเล่นแยกจากเกมเรา) · จัดทำ: ตุลาคม 2026
> **วัตถุประสงค์:** เรียนรู้ว่ากลไกของเกมที่ใกล้เคียงเรา "รู้สึกอย่างไรเวลาเล่น" แล้วเอามาเทียบกับเกมเรา **ไม่ใช่ของที่จะนำไปวางขาย** เนื้อหาทั้งหมดเป็นของที่ผมตั้งขึ้นเอง ไม่ใช้ชื่อ ภาพ หรือเนื้อหาของเกมต้นฉบับ (ลอกแค่แนวคิดกลไกทั่วไปเพื่อศึกษา)

## 1. สิ่งที่ต้องรู้ก่อนอ่านต่อ

- **ข้อมูลต้นฉบับของผมมีจำกัด:** ผมเปิดบทความเต็มของเกมต้นฉบับไม่ได้ (เครือข่ายจำกัดโดเมน) ใช้ได้แค่ข้อความตัดตอนจากผลค้นหา ([Pocket Tactics: การกลายพันธุ์](https://www.pockettactics.com/grow-a-garden-mutations), [BlueStacks: คู่มือมือใหม่](https://www.bluestacks.com/blog/game-guides/roblox/rl-grow-a-garden-beginners-guide-en.html), [Sportskeeda: ทำไมถึงดัง](https://www.sportskeeda.com/roblox-news/why-grow-garden-popular)) กับความจำของผมเอง และสิ่งที่คุณเล่าไว้ตอนต้นของบทสนทนา
- **ตัวเลขทุกตัวเป็นของผม** ตั้งให้ "ได้ฟีลคล้ายกัน" ไม่ใช่ค่าจริงของเกมนั้น (ตัวเลขที่ตรวจได้จากผลค้นมีแค่ ตัวคูณกลายพันธุ์ช่วง ×2 ถึง ×100, โอกาสสายรุ้ง ~0.1%, สัตว์เลี้ยงให้โบนัสแฝง และมีสปริงเกอร์/อุปกรณ์เร่งการโต)
- ผลทดสอบทั้งหมดมาจากบอทที่ผมเขียน **ไม่ใช่ผู้เล่นจริง** จึงบอกได้เรื่องจังหวะและโครงสร้าง บอกความสนุกไม่ได้

## 2. กลไกที่ทำในโคลน

| ส่วน | กติกาในโคลน |
|---|---|
| ปลูก | 12 ที่ดิน (เริ่ม 6 ซื้อเพิ่มได้) เลือกเมล็ด แตะที่ดินว่างเพื่อปลูก หรือกด "ปลูกทั้งหมด" |
| โต | เมล็ด 8 ชนิด 5 ระดับ ใช้เวลา 8–220 วิ บางชนิดเก็บซ้ำได้หลายรอบ (ปลูกครั้งเดียว) |
| เก็บ | แตะที่ดินที่พร้อมเพื่อเก็บ หรือ "เก็บทั้งหมด" กระเป๋าจุ 120 ผล เต็มแล้วเก็บไม่ได้ |
| ผลไม้แต่ละผล | **ขนาดสุ่ม** 0.75–1.35× และ **กลายพันธุ์สุ่ม** (ทอง ×15, รุ้ง ×40 หายาก; เปียก/เย็น/ช็อตเมื่อมีสภาพอากาศตรงกัน) ราคาจึงต่างกันทุกผล |
| ขาย | ขายทั้งกระเป๋าทีเดียว (รับเหรียญตามมูลค่ารวม) |
| ร้านเมล็ด | **รีสต็อกทุก 5 นาที** จำนวนสุ่มต่อชนิด เมล็ดแพงโผล่น้อยหรือไม่โผล่เลย (โอกาสปรากฏ 100% / 55% / 30% / 12% / 4% ตามระดับ) |
| สภาพอากาศ | สุ่มทุก 90–200 วิ นาน 60 วิ (ฝน/น้ำค้างแข็ง/พายุ) เปิดโอกาสกลายพันธุ์ |
| อุปกรณ์ | สปริงเกอร์ 🪙800: พืชทั้งสวนโตเร็ว ×1.5 นาน 120 วิ (ซ้อนเวลาได้) |
| สัตว์เลี้ยง | ซื้อไข่ 3 ระดับ รอฟัก ได้สัตว์สุ่ม 4 ชนิด สวมได้ 3 ตัว โบนัส: ราคาขาย / โตเร็ว / โอกาสกลายพันธุ์ / ผลใหญ่ขึ้น |

ปุ่ม "ปลูกทั้งหมด / เก็บทั้งหมด" เป็นของที่ผมเพิ่มเอง ต้นฉบับใช้การแตะทีละจุดและเดินไปมา

## 3. สิ่งที่เห็นจากบอท (กดเก็บ-ขาย-ซื้อ-ปลูกทุก ~6 วินาที เกม 1 ชั่วโมง)

| จุด | เวลาที่เริ่มปลูกครั้งแรก |
|---|---|
| แครอท (เมล็ดเริ่มต้น) | 10 วิ |
| สตรอว์เบอร์รี | 22 วิ |
| บลูเบอร์รี | 82 วิ |
| สัตว์เลี้ยงตัวแรก | ~166 วิ |
| มะเขือเทศ / ฟักทอง | ~5 นาที / ~6 นาที |
| ครบ 12 ที่ดิน | ~11.5 นาที |
| ข้าวโพด / ผลมังกร | ~25 นาที / ~30 นาที |
| แตงทิพย์ (ระดับสูงสุด) | ไม่ถึงใน 60 นาที |

- ชั่วโมงแรก: เก็บ 924 ผล เหรียญ ~895K · **บอทมีรอบที่ "ว่างงาน" ประมาณ 64%** คือมีที่ดินว่างแต่ซื้อเมล็ดไม่ได้ (ของที่ซื้อไหวหมดสต็อก หรือเงินไม่พอสำหรับของที่มี) ต้องรอรีสต็อก 5 นาที
- เมล็ดระดับสูงโผล่ในร้านไม่สม่ำเสมอ ทำให้จังหวะการไต่ระดับสะดุดเป็นช่วงๆ ตามโชคของร้าน

## 4. เทียบกับเกมเรา: ความสนุก/แรงกดดัน มาจากไหน

| เรื่อง | โคลน (ฟาร์ม) | เกมเรา (สัตว์) |
|---|---|---|
| **ความแน่นอนของผลผลิต** | **ผันผวน** ขนาดและกลายพันธุ์สุ่มทุกผล ได้ลุ้นตอนเก็บ | **คงที่** สัตว์ชนิดเดียวกันได้ของมูลค่าเท่ากันทุกครั้ง |
| **ของที่หายาก** | **ขาดตลาด** ร้านรีสต็อกตามเวลา ต้องรอ/เฝ้า | ได้จากการสำรวจ/ผสม (ต้องค้นหา) |
| **การเลือกลงทุน** | เลือกเมล็ดจากสต็อกจำกัด ซื้ออะไรก่อน ถือเงินรอของแพงหรือไม่ | เลือกสัตว์ลงช่อง (บทบาท ตำแหน่งติดกัน) และผสมสูตรไหน |
| **การปรุง** | ไม่มี ขายผลไม้ตรงๆ | โยนลงหม้อ ขั้นบันไดเมนู |
| **การขาย** | ขายทั้งกระเป๋า | ตลาดอิ่ม ลูกค้าต้องการ ออเดอร์ |
| **สะสม/ค้นพบ** | แทบไม่มี | สมุดภาพ 27 ชนิด สูตรผสม (จุดเด่นที่ผู้เล่นชอบ) |
| **สภาพอากาศ** | มี (หน้าต่างสั้นๆ ที่ผลกลายพันธุ์ได้) | ไม่มี |
| **สัตว์เลี้ยง** | โบนัสแฝง 4 แบบ สวม 3 ตัว | บทบาทของสัตว์ในช่องฟาร์ม (ลึกกว่า) |
| **ความจุจำกัด** | กระเป๋าเต็ม ต้องขายบ่อย | กระเป๋า/กองหน้าช่องเต็มแล้วหยุด (คล้ายกัน) |
| **เวลารอ** | โต 8–220 วิ + รอรีสต็อก 5 นาที | ผลิต 3–7 วิ ปรุง 5 วิ ผสม 4 วิ–2.5 นาที |

**ข้อสรุปเชิงโครงสร้าง (จากการเทียบ ไม่ใช่จากผู้เล่นจริง):**
- เกมต้นแบบสร้างความตื่นเต้นจาก **ความผันผวน (ลุ้น)** และ **ความขาดแคลน (รอ/ล่า)** เป็นหลัก ส่วนการตัดสินใจเชิงกลยุทธ์ค่อนข้างตื้น
- เกมเราตรงข้าม: **ลึกเชิงการเลือกและการค้นพบ แต่ผลลัพธ์คาดเดาได้ทั้งหมด** ไม่มีช่วงที่ "ลุ้น" เลย (นี่อาจเป็นเหตุผลที่ผู้เล่นรู้สึกว่าตื้น แม้จะมีระบบเยอะ ซึ่งเป็นข้อสันนิษฐานของผม ต้องทดสอบ)

## 5. ข้อเสนอที่เอามาปรับกับเกมเรา (เรียงตามคุ้มค่า)

| # | แนวคิดจากโคลน | ปรับให้เข้ากับเกมเรา | ขนาด | ความเสี่ยง |
|---|---|---|---|---|
| 1 | **ผลไม้กลายพันธุ์/ขนาดสุ่ม** | **ผลผลิตกลายพันธุ์:** ของที่เก็บมีโอกาสเป็น "ไข่ทอง/นมพิเศษ" ตัวคูณ ×3 ถึง ×25 โอกาสต่ำ และ **ขนาดสุ่ม ±25%** ต่อชิ้น ผู้เร่งผสม/ผู้หนุนเพิ่มโอกาสได้ มีข้อความ ✨ ในบันทึกเหตุการณ์ | เล็ก | ต้องกันไม่ให้ผลรวมของมูลค่าในหม้อแกว่งจนบันไดเมนูเดาไม่ได้ (แสดงมูลค่ารวมจริงอยู่แล้ว จึงน่าจะรับได้) |
| 2 | **สภาพอากาศเป็นช่วงสั้นๆ** | **เหตุการณ์ 60 วินาที** เช่น "ฝนทองคำ" ผลผลิตกลายพันธุ์บ่อยขึ้น เตือนให้เก็บ/โยนตอนนั้น มีแต่ข้อดี ไม่เสียถ้าพลาด (ตามหลักไม่ลงโทษ) | เล็ก–กลาง | ผู้เล่นที่วางไว้ข้างจอจะพลาดบ่อย ควรมีเงื่อนไขว่าได้ผลแม้พลาด |
| 3 | **ร้านรีสต็อก/ของขาดตลาด** | **พ่อค้าเร่:** ปรากฏเป็นรอบ ขายวัตถุดิบหายาก/ไข่/สัตว์ตัวเดียวในจำนวนจำกัด ให้เหตุผลกลับมาดูแบบเป็นบวก | กลาง | บอทพบว่ารอบรีสต็อกทำให้ "ว่างงาน" ~64% ซึ่งขัดกับที่ผู้เล่นอยากได้ (คลิกไว ไม่ต้องรอ) ถ้านำมาใช้ควรเป็น **ของเสริม** ไม่ใช่ทางเดียวที่จะก้าวหน้า |
| 4 | **หลายรอบจากพืชต้นเดียว** | เทียบกับสัตว์ที่ผลิตต่อเนื่องอยู่แล้ว | – | ไม่ต้องทำ |
| 5 | **สวมสัตว์เลี้ยงให้โบนัสแฝง** | เทียบกับบทบาทในช่องฟาร์ม (เรามีลึกกว่า) | – | ไม่ต้องทำ |

**สิ่งที่โคลนแสดงว่าเกมเราได้เปรียบ (ควรรักษาไว้):** สมุดสูตรและการค้นพบ, ตลาดอิ่ม/ออเดอร์ทำให้การขายมีการตัดสินใจ, บทบาทและตำแหน่งในฟาร์ม

**ข้อ 1 คือข้อที่ผมแนะนำให้ทำก่อน** เพราะเกมเรายังไม่มี "ช่วงที่ลุ้น" เลยทั้งที่เป็นสิ่งที่เกมที่ใกล้เคียงใช้สร้างความตื่นเต้นหลัก ทำได้ในโปรโตไทป์ไม่กี่สิบบรรทัด

## 6. ที่ยังไม่รู้

| คำถาม | วิธีหาคำตอบ |
|---|---|
| ผู้เล่นรู้สึกว่าโคลน "ใกล้เคียงต้นฉบับ" แค่ไหน | ให้คุณลองเล่นแล้วบอกว่าตรงไหนต่างจากเกมที่คุณเล่นจริง (ผมปรับตามได้) |
| ความผันผวนทำให้สนุกขึ้น หรือรู้สึกเหมือนการพนันที่ไม่ให้ผู้เล่นควบคุม | ลองใส่ข้อ 1 ในเกมเราแล้วดูปฏิกิริยา |
| รอรีสต็อกน่าหงุดหงิดไหมในมุมมองของผู้เล่นคุณ | ลองเล่นโคลนที่ ×1 สักพัก |
