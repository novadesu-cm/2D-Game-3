## 0. สถานะเอกสาร

**ตัดออกจากการออกแบบเดิม**

| ระบบที่ตัด | เหตุผล |
|---|---|
| ระบบผู้พิทักษ์ (Guardian) | ผู้เล่นสั่งตัด |
| การป้อนอาหาร / ต้องกลับมากดเลี้ยง | ผู้เล่นสั่งตัด และขัดกับการเล่นข้างจอ |
| ทุกอย่างที่ "ลงโทษ" ตอนผู้เล่นไม่อยู่ | สัตว์ไม่หิว ไม่ป่วย ไม่ตาย ไม่หนีไป |

ข้อกำหนดข้อนี้ใช้กับทุกฟีเจอร์ที่เพิ่มในอนาคตด้วย: **ห้ามมีระบบที่บังคับให้ผู้เล่นต้องกลับมากดภายในเวลาที่กำหนด**

**ข้อกำหนดจากผู้เล่น (ต้นฉบับ)**

1. เกมแนว Idle บรรยากาศฟาร์ม แต่เป็นการเลี้ยงสัตว์
2. ผสมสัตว์เพื่อหาสัตว์ชนิดใหม่
3. สัตว์ที่วางลงช่องต้อง **มีประโยชน์** อย่างใดอย่างหนึ่ง
4. สัตว์ที่เกินจำนวนช่อง ต้อง **เก็บ/ดอง** ไว้ใน "ช่องเก็บสัตว์" ได้
5. เล่นข้างจอ (วางหน้าต่างเล็กๆ ไว้ข้างงานอื่น)
6. ถ้าข้อกำหนดข้อไหนขัดกับการเป็นเกมที่ดี ให้เอาเกมที่ดีก่อน

## 1. ข้อกำหนดที่ถูกปรับเพื่อให้เป็นเกมที่ดี

ตามข้อ 6 ผมไล่ตรวจแล้ว ข้อที่ต้องปรับหรือเติมมีดังนี้ ถ้าไม่เห็นด้วยข้อไหนบอกได้ เพราะแต่ละข้อแก้แยกกันได้

| # | ข้อกำหนดเดิม | ปัญหาถ้าทำตรงๆ | สิ่งที่ออกแบบจริง |
|---|---|---|---|
| A | "สัตว์ในช่องต้องมีประโยชน์" | ถ้าทุกตัวแค่ "ผลิตเหรียญ" ผู้เล่นไม่มีการตัดสินใจ เอาตัวแรงสุดใส่ก็จบ | แบ่ง **5 บทบาท** (ผลิต / หนุนข้างเคียง / เร่งผสม / เร่งสำรวจ / เฝ้าฟาร์ม) ช่องมีจำกัด ใส่บทบาทหนึ่งต้องเสียอีกบทบาทหนึ่ง และมี **การวางตำแหน่งติดกัน** ทำให้ตำแหน่งมีผล |
| B | "สัตว์เกินให้ดองไว้" | ช่องเก็บที่เก็บเฉยๆ กลายเป็นแค่ตัวนับที่เต็มแล้วน่ารำคาญ | ช่องเก็บเป็น **คลังพ่อแม่พันธุ์ + คลังลูกเรือสำรวจ + วัตถุดิบรวมดาว** สัตว์เก่าอ่อนแรงก็ไม่ไร้ค่า (ดูข้อ 5.3) |
| C | ผสมแล้วสุ่มหาสัตว์ใหม่ | ถ้าต้องไล่ลองคู่แบบมั่วๆ และแต่ละคู่ต้องรอเวลา จะรู้สึกเหมือนเสียเวลา ไม่ใช่การค้นพบ | มี **ระบบใบ้สูตร** และ **ตัวนับกันซวย (pity)** ผู้เล่นเดาสูตรได้อย่างมีเหตุผล ไม่ต้องสุ่มบริสุทธิ์ |
| D | เล่นข้างจอ | แอนิเมชันหนักๆ หรือเหตุการณ์ที่ต้องรีบกด ใช้ไม่ได้ | ทุกการดูแลใช้เวลาไม่เกิน ~30 วินาที ไม่มีสถานะแพ้ ไม่มีกิจกรรมจับเวลาที่พลาดแล้วเสียของ และกินแรงเครื่องต่ำ (ดูข้อ 8) |
| E | ตัดการป้อนอาหาร | เกม Idle ที่ไม่มีเหตุผลให้ "กลับมา" จะจืด | เหตุผลที่กลับมาเป็นเรื่องบวก ไม่ใช่บังคับ: ไข่ฟัก, สำรวจเสร็จ, ปลดล็อกสูตร, คิวเลือกวางสัตว์ใหม่ ปล่อยทิ้งไว้ก็ไม่เสียอะไร |
| F | ไม่ได้ระบุ | ไม่มีเป้าหมายระยะยาว เล่นแล้วตันเร็ว | **สมุดภาพ (Codex)** เป็นเป้าหมายหลัก และ **ย้ายถิ่น (Migration/Prestige)** เป็นวงรอบระยะยาว (เฟส 2) |

## 2. เสาหลักของเกม (Design Pillars)

1. **เปิดทิ้งไว้ก็สนุก** — เกมเดินเองทุกอย่าง การกลับมาดูคือรางวัล ไม่ใช่หน้าที่
2. **ทุกตัวมีที่ทางของมัน** — ไม่มีสัตว์ที่ "ได้มาแล้วไร้ประโยชน์ทันที"
3. **ค้นพบ ไม่ใช่สุ่มเปล่า** — การผสมคือการไขปริศนาสูตร มีเบาะแสให้
4. **ไม่มีการลงโทษ** — ไม่มีหาย ไม่มีตาย ไม่มีหมดเวลา ไม่มีล็อกอินรายวัน
5. **อ่านออกในหน้าต่างเล็ก** — เห็นสถานะทั้งหมดได้ในพื้นที่ ~360×480 พิกเซล

## 3. วงจรการเล่น

### 3.1 วงจรหลัก (ระยะยาว)

```
        ┌─────────── ได้ "เหรียญ" ต่อวินาที ───────────┐
        ▼                                              │
   [ฟาร์ม: สัตว์ในช่อง]  ──ซื้อช่อง/อัปเกรด/จ่ายค่าผสม──►  [เหรียญ]
        ▲                                              │
        │ เลือกสัตว์ที่เก่งขึ้นมาวาง                     │
        │                                              ▼
   [ช่องเก็บสัตว์] ◄── ไข่ฟัก ◄── [โรงผสม] ◄──── พ่อแม่จากฟาร์ม/ช่องเก็บ
        ▲                                              
        └────── สัตว์ป่าใหม่ ◄── [สำรวจ] ◄── ลูกเรือจากช่องเก็บ
```

### 3.2 วงจรการเข้ามาดู (ครั้งละ 10–30 วินาที ทุก 5–20 นาที)

1. ดูว่ามีอะไรเสร็จ (ไข่ฟัก / สำรวจกลับมา) → เก็บของ
2. ตัดสินใจ 1–3 อย่าง: สัตว์ใหม่ตัวนี้ **ลงช่องฟาร์ม** หรือ **เข้าช่องเก็บ**?
3. เริ่มผสมคู่ใหม่ / ส่งสำรวจรอบใหม่ (มีปุ่ม "ทำซ้ำรอบที่แล้ว" กดเดียวจบ)
4. ใช้เหรียญซื้ออะไรสักอย่าง แล้วปล่อยเกมไว้

## 4. ระบบฟาร์มและสัตว์

### 4.1 สัตว์

คุณสมบัติของสัตว์หนึ่งตัว:

| ฟิลด์ | คำอธิบาย |
|---|---|
| ชนิด (Species) | 27 ชนิดในเวอร์ชันแรก (ข้อ 6) |
| ระดับความหายาก | สามัญ / พิเศษ / หายาก / มหากาพย์ / ตำนาน |
| บทบาท | 1 อย่าง (ตำนานมี 2 อย่าง) ดูข้อ 4.2 |
| ดาว ★ | 1–3 เพิ่มได้โดยรวมสัตว์ชนิดเดียวกัน (ข้อ 5.3) |
| สีพิเศษ (Variant) | โอกาสน้อยตอนฟักไข่ แรงขึ้น ×1.5 และมีช่องในสมุดภาพแยก |

**ไม่มีเลเวลต่อตัว ไม่มีการป้อน ไม่มีค่าความสุข** ความแรงมาจาก ความหายาก × ดาว × สีพิเศษ × ตำแหน่งในฟาร์ม เท่านั้น (ลดงานกดซ้ำๆ ที่ไม่เหมาะกับการเล่นข้างจอ)

### 4.2 บทบาท (นี่คือ "ประโยชน์" ของสัตว์ในช่อง)

| บทบาท | ผลตอนวางในช่องฟาร์ม | ผลิตเหรียญเอง? |
|---|---|---|
| 🪙 ผู้ผลิต (Producer) | ผลิตเหรียญต่อวินาที | ผลิตเอง |
| 📣 ผู้หนุน (Booster) | เพิ่ม % ให้ช่อง **บน/ล่าง/ซ้าย/ขวา** ที่ติดกัน | ไม่ผลิตเอง |
| 💞 ผู้เร่งผสม (Breeder) | ลดเวลาผสมทุกคู่ และเพิ่มโอกาสสีพิเศษ (รวมกันทั้งฟาร์ม) | ไม่ผลิตเอง |
| 🧭 ผู้เร่งสำรวจ (Scout) | ลดเวลาสำรวจ และเพิ่มคุณภาพของที่ได้ (รวมกันทั้งฟาร์ม) | ไม่ผลิตเอง |
| 🏠 ผู้เฝ้าฟาร์ม (Keeper) | เพิ่มเพดานเวลาออฟไลน์ และเพิ่มความจุช่องเก็บ | ไม่ผลิตเอง |

สัตว์ **ตำนาน** มี 2 บทบาทในตัวเดียว จึงคุ้มกับที่ต้องใช้เวลาไต่มานาน

**ทำไมถึงเป็น "การตัดสินใจ" จริงๆ:** ช่องฟาร์มเริ่มที่ 3 ช่อง ขยายได้ถึง 12 ช่อง (กริด 4×3) ผู้เล่นต้องแลกกัน เช่น ใส่ผู้ผลิตให้หมดเพื่อเงินเร็ว หรือแบ่งช่องให้ผู้เร่งผสมเพื่อให้ไต่ระดับหายากเร็วขึ้น และตำแหน่งผู้หนุนต้องไปอยู่ข้างผู้ผลิตที่แรงที่สุด

### 4.3 ช่องฟาร์ม

- กริด 4 คอลัมน์ × 3 แถว ปลดล็อกทีละช่องตามลำดับคงที่ (ซ้ายบน → ขวาล่าง)
- ช่องที่ยังไม่ซื้อแสดงเป็นเงา พร้อมราคา
- ย้ายสัตว์ระหว่างช่องฟาร์มกับช่องเก็บได้ทันที ไม่มีค่าใช้จ่าย ไม่มีคูลดาวน์
- สูตรผลผลิตของผู้ผลิตหนึ่งตัว:

```
เหรียญ/วิ  = ฐานตามความหายาก × ตัวคูณดาว × ตัวคูณสีพิเศษ
             × (1 + ผลรวม % จากผู้หนุนข้างเคียง)
             × ตัวคูณทั้งฟาร์ม (อัปเกรด + ย้ายถิ่น)
```

## 5. ระบบรอง

### 5.1 โรงผสม (Nursery)

- เริ่มต้นมี 1 ช่องผสม ปลดล็อกเพิ่มได้ถึง 3 (ใช้ "แก่นธรรมชาติ")
- วางพ่อแม่ 2 ตัว จ่ายเหรียญ รอเวลา แล้วได้ **ไข่ 1 ฟอง** ไปไว้ในช่องเก็บ (ฟักเองอัตโนมัติ)
- **พ่อแม่ไม่ถูกใช้หมด** แต่ระหว่างผสมจะถูกล็อก ถ้าดึงมาจากช่องฟาร์ม ช่องนั้นจะว่างและหยุดทำงานจนกว่าจะเสร็จ (ราคาของการเลือก) ถ้าดึงจากช่องเก็บ ไม่เสียอะไร
- ผลลัพธ์การผสม (ไม่สนลำดับพ่อแม่):

| คู่พ่อแม่ | ผลลัพธ์ |
|---|---|
| ตรงสูตร | สัตว์ตามสูตร (ข้อ 6.2) |
| ชนิดเดียวกัน | ชนิดเดิมแน่นอน (ใช้หาตัวซ้ำไปรวมดาว) |
| ไม่ตรงสูตร ชนิดต่างกัน | สุ่มเป็นชนิดของพ่อหรือแม่ (50/50) |
| ทุกกรณี | โอกาสออก **สีพิเศษ** 5% (+ ผู้เร่งผสม) |

- สูตรที่ลองแล้วไม่ตรงจะบันทึกใน "ประวัติการลอง" เพื่อไม่ให้ผู้เล่นต้องจำเอง
- เวลาผสมตามความหายากของลูก: สามัญ 20 วิ · พิเศษ 2 นาที · หายาก 10 นาที · มหากาพย์ 1 ชม. · ตำนาน 4 ชม. (ผู้เร่งผสมลดได้สูงสุด −60%)

**ระบบใบ้สูตร (ลดความมั่ว):**
- เมื่อผู้เล่นมีพ่อหรือแม่ตัวหนึ่งของสูตร สมุดภาพจะแสดง "เงาสัตว์ + ใช้ [ชื่อสัตว์ที่ตัวเองมี] + ?" ให้เห็น
- การสำรวจมีโอกาสได้ "เบาะแสสูตร" เปิดสูตรเต็มให้ 1 สูตร

### 5.2 การสำรวจ (Expedition)

- ส่ง **ลูกเรือ 1–3 ตัว จากช่องเก็บ** ไปโซนต่างๆ ลูกเรือกลับมาพร้อมของรางวัล ตอนอยู่ข้างนอกจะใช้ทำอย่างอื่นไม่ได้ (ทำให้สัตว์ในช่องเก็บมีงานทำ)
- โซนและเงื่อนไขปลดล็อก (นับจำนวนชนิดที่ค้นพบในสมุดภาพ):

| โซน | ปลดล็อกเมื่อค้นพบ | ได้อะไร | เวลา |
|---|---|---|---|
| 1 ทุ่งหญ้า | 0 | สัตว์ป่าสามัญ, เหรียญ | 30 วิ (สอนเล่น) – 5 นาที |
| 2 ลำธาร | 6 | สามัญ + โอกาสต่ำที่จะเจอระดับพิเศษ, เบาะแสสูตร | 30 นาที |
| 3 ป่าลึก | 12 | ถึงระดับหายาก, แก่นธรรมชาติ | 2 ชม. |
| 4 ภูผาเมฆ | 18 | ถึงระดับมหากาพย์ | 6 ชม. |
| 5 ถ้ำนาคา | 24 | ถึงระดับตำนาน (เจอยากมาก) | 12 ชม. |

- ของรางวัลที่ได้: **ไข่ลึกลับ** (สัตว์ป่าชนิดที่ยังไม่มี มีน้ำหนักสูงกว่า) · เหรียญก้อนใหญ่ (เทียบเท่ารายได้ N นาที) · เบาะแสสูตร · แก่นธรรมชาติ
- ความหายากรวมของลูกเรือและจำนวนลูกเรือเพิ่มคุณภาพของที่ได้ ผู้เร่งสำรวจในฟาร์มช่วยลดเวลา
- **กันซวย (pity):** ถ้าไม่ได้ของระดับสูงสุดของโซนติดกัน N รอบ รอบถัดไปการันตี
- ไม่มีความเสี่ยงที่ลูกเรือจะหายหรือบาดเจ็บ

### 5.3 ช่องเก็บสัตว์ ("ตู้ดอง")

"ดอง" ตามคำที่ผู้เล่นใช้ ผมตีความว่า **เก็บไว้ก่อนโดยไม่เสีย** ถ้าอยากให้ "ดอง" หมายถึงสัตว์เก็บนานแล้วได้โบนัสด้วย บอกได้ ดูข้อ 11

- ความจุเริ่ม 12 ตัว ขยายด้วยแก่นธรรมชาติและผู้เฝ้าฟาร์ม (สูงสุด ~100)
- สัตว์ในช่องเก็บ **ไม่ผลิต ไม่ทำงานบทบาท** (ไม่งั้นช่องฟาร์มไร้ความหมาย) แต่ใช้ได้ 4 ทาง:
  1. **เป็นพ่อแม่พันธุ์** ส่งเข้าโรงผสมโดยไม่ทำให้ฟาร์มเสียรายได้
  2. **เป็นลูกเรือสำรวจ**
  3. **รวมดาว:** ชนิดเดียวกัน 3 ตัวที่ดาวเท่ากัน → 1 ตัวดาว +1 (สูงสุด ★3 ในเวอร์ชันแรก) ดาวคือที่ระบายตัวซ้ำ
  4. **ปล่อยคืนธรรมชาติ:** แลกเป็นเหรียญนิดหน่อย + **แก่นธรรมชาติ** (ตามความหายาก) ใช้ปลดล็อกถาวร
- **ช่องเก็บเต็ม ไม่ทำให้อะไรหาย** — ไข่ที่ฟักแล้วจะค้างรอในโรงผสมจนกว่าจะมีที่ว่าง ผู้เล่นเลือกปล่อย/รวมดาวสัตว์ตัวเก่าได้ตอนนั้น
- มีปุ่มจัดเรียง/กรอง ตามบทบาทและความหายาก และปุ่ม "ปล่อยตัวซ้ำที่ไม่จำเป็น" ที่เหลือสัตว์ที่ยังขาดดาวอยู่ไว้

### 5.4 เศรษฐกิจ

มีเงินตราเพียง 2 อย่าง (น้อยเพื่อให้อ่านง่ายในหน้าต่างเล็ก):

| สกุล | ได้จาก | ใช้ซื้อ |
|---|---|---|
| 🪙 เหรียญ | ผู้ผลิต, สำรวจ, ปล่อยสัตว์ | ช่องฟาร์ม, ค่าผสม, อัปเกรดฟาร์ม (ตัวคูณทั้งฟาร์ม) |
| 🌿 แก่นธรรมชาติ | ปล่อยสัตว์, สำรวจโซนสูง | ช่องผสม/ช่องสำรวจเพิ่ม, ขยายช่องเก็บ, ปุ่ม "ทำซ้ำ/เก็บอัตโนมัติ", ย้ายถิ่น (เฟส 2) |

ไม่มีเงินจริงในเวอร์ชันนี้ (ดูข้อ 11)

### 5.5 ออฟไลน์

- เหรียญสะสมได้ตอนปิดเกม เพดานเริ่ม **4 ชม.** เพิ่มด้วยผู้เฝ้าฟาร์ม (สูงสุด 24 ชม.)
- ไข่และการสำรวจนับเวลาจริง ฟักและเสร็จตอนปิดเกมได้
- เปิดเกมขึ้นมามีหน้าสรุป "ระหว่างที่ไม่อยู่" (เหรียญที่ได้, ไข่ที่ฟัก, สำรวจที่เสร็จ)

### 5.6 สมุดภาพ (Codex) และเป้าหมาย

- 27 ชนิด × (ปกติ / สีพิเศษ) พร้อมเงาสัตว์ของที่ยังไม่เจอ และสูตรที่ค้นพบแล้ว
- ใช้เป็นเงื่อนไขปลดล็อกโซนสำรวจ และเป็นเป้าหมายระยะยาวหลัก
- ภารกิจสั้นๆ แบบไม่จับเวลา ("มีผู้หนุน 2 ตัวติดกัน", "ผสมสูตรแรกสำเร็จ") ให้เป้าหมายทีละขั้นระหว่างนำทางเกม

### 5.7 ย้ายถิ่น (Prestige) — เฟส 2

รีเซ็ตเหรียญ ช่องฟาร์ม และอัปเกรดฟาร์ม แลกกับ "ตัวคูณถาวร" **เก็บ: สมุดภาพ, สูตรที่ค้นพบ, ช่องเก็บและสัตว์ในนั้น, ช่องผสม/สำรวจที่ซื้อ** ไว้ รายละเอียดจะออกแบบหลังจบการทดสอบเฟส 1

## 8. การเล่นข้างจอ — UX และเทคนิค

### 8.1 หลักการ

- ทุกอย่างอ่านออกได้ในแวบเดียว ไม่ต้องเลื่อนหน้า
- แจ้งเตือนแบบเบา: ป้ายแดงบนปุ่ม + เสียงเตือนเบาๆ (ปิดได้) ไม่มีป๊อปอัปบังหน้าจอ
- เสียงปิดเป็นค่าเริ่มต้น
- ไม่มีสิ่งใดต้องพลาด ไม่มีกิจกรรมจำกัดเวลา

### 8.3 โหมดแถบเล็ก (Mini mode)

ย่อเหลือแถบ ~360×120 เห็นเฉพาะรายได้ ไข่/สำรวจเสร็จหรือยัง และมีป้ายแจ้งเตือน เหมาะวางไว้ขอบจอตอนทำงานอื่น

### 8.4 ฟีเจอร์หน้าต่าง

| ฟีเจอร์ | หมายเหตุ |
|---|---|
| อยู่บนสุดเสมอ (Always on top) | ปุ่มสลับ |
| ลากย้ายได้, ปรับขนาดได้, จำตำแหน่ง | |
| ความโปร่งใสปรับได้ | ตอนเมาส์ไม่อยู่บนหน้าต่าง |
| เล่นต่อเมื่อไม่ได้โฟกัส | `Application.runInBackground = true` |
| ลดเฟรมเรตเมื่อไม่โฟกัส | โฟกัส 30 fps / ไม่โฟกัส 10 fps / ย่อ 2 fps (คำนวณเกมด้วยเวลาจริง ไม่ผูกกับเฟรม) |

### 8.5 หมายเหตุสถาปัตยกรรม (Unity 6)

- **ข้อมูลเป็น ScriptableObject:** `SpeciesData`, `RecipeData`, `ZoneData`, `UpgradeData` — เพิ่มสัตว์โดยไม่ต้องแก้โค้ด
- **แยก simulation ออกจาก view:** คำนวณด้วยเวลา UTC และสูตรปิด (`เหรียญ += อัตรา × Δt`) ใช้ตัวเดียวกันทั้งตอนเล่นและตอนคำนวณออฟไลน์
- **เซฟ:** JSON ในเครื่อง มีเลขเวอร์ชัน เซฟอัตโนมัติทุก 30 วินาทีและตอนปิดเกม เขียนแบบ atomic (เขียนไฟล์ชั่วคราวแล้วเปลี่ยนชื่อ)
- **ตัวเลข:** ใช้ `double` พร้อมตัวจัดรูปแบบ (K, M, B, …) พอสำหรับเฟส 1 ถ้าตัวคูณย้ายถิ่นทำให้เกินช่วง ค่อยย้ายไปแบบ BigDouble
- **อัปเดต UI เมื่อข้อมูลเปลี่ยนเท่านั้น** (event-driven) ไม่ poll ทุกเฟรม
- **ฟังก์ชันหน้าต่าง (always-on-top, ไร้ขอบ, โปร่งใส):** ใช้ Win32 API (`user32.dll` — `SetWindowPos` ฯลฯ) ได้เฉพาะ **Windows** บนแพลตฟอร์มอื่นต้องใช้วิธีของมันเอง → ต้องยืนยันแพลตฟอร์มเป้าหมาย (ข้อ 11)
- **สไตล์ภาพ (เสนอ):** สีพาสเทลนุ่มๆ ตัวการ์ตูนเรียบๆ อ่านออกที่ขนาด ~48 พิกเซลต่อตัว แอนิเมชันกระดิกเบาๆ ไม่กี่เฟรม

## 13. ปรับดีไซน์ v0.2 — เพิ่มความลึกด้วยสายพานผลผลิต

**ที่มา:** ผู้เล่นรู้สึกว่าเวอร์ชันแรกตื้น (สัตว์ผลิตเหรียญตรงๆ) ต้องการวงจรแบบเกมปลูกผักใน Roblox: เก็บ → ปรุง → ขาย แล้วใช้เงินปลดล็อกระบบอัตโนมัติทีละชั้น

**หลักการที่ยืมมา:** ความลึกของเกมแนวนี้ไม่ได้มาจากการเดิน แต่มาจาก **บันไดทำเองเร็ว → ปลดล็อกอัตโนมัติที่ช้ากว่า → อัปเกรดให้เร็วขึ้น** และ **คอขวดที่ย้ายไปเรื่อยๆ** (ผลิตเร็วกว่าที่โดรนเก็บทัน → กระเป๋าเต็ม → หม้อไม่พอ → ตู้โชว์เต็ม ฯลฯ)

**ที่ไม่เอามา:** การเดินไปมาในแผนที่ ขัดกับเกมข้างจอ (หน้าต่างเล็ก ต้องมีส่วนที่ทำเองได้แค่กดปุ่ม) จึงใช้ปุ่มสถานีแทน ส่วนความรู้สึก "ทำเองเร็วกว่า" ยังอยู่ เพราะตอนอยู่หน้าจอกดเก็บ/ปรุง/ขายเองได้ทันที ขณะที่ระบบอัตโนมัติทำงานตามจังหวะของมัน

### 13.1 สายพานผลผลิต

```
สัตว์ผู้ผลิต → (แถบผลิตเต็ม) → กองหน้าช่อง → [เก็บเอง / โดรน] → กระเป๋า
   → [โยนลงหม้อ 2–3 ชิ้น / เชฟอัตโนมัติ] → ตู้โชว์ → [ขายเอง / แคชเชียร์] → เหรียญ
```

- **ผู้ผลิต** ไม่ให้เหรียญแล้ว แต่ให้ **ผลผลิต** 3 ตระกูล: 🥚 ไข่ (ไก่ เป็ด ห่าน) · 🥛 นม (แกะ อัลปาก้า แกะขนทอง) · 🌰 ของป่า (บีเวอร์ กวางทองคำ กินรี)
- ผลผลิตสะสมเป็น **กองหน้าช่อง** (เริ่มที่ 3 ชิ้น) กองเต็มแล้วสัตว์ **หยุดผลิต** (ไม่มีโทษอื่น) นี่คือเหตุผลที่ต้องเก็บ หรือมีโดรน
- มูลค่าผลผลิตต่อชิ้น: 6 / 24 / 96 / 384 / 1,536 ตามระดับความหายาก · ความเร็วผลิต 8–16 วิต่อชิ้น (ดาวและสีพิเศษเพิ่มความเร็ว ผู้หนุนเพิ่มความเร็วช่องข้างเคียง)
- **หม้อ:** ใส่ 2–3 ชิ้น มูลค่าอาหาร = ผลรวมมูลค่าวัตถุดิบ × ตัวคูณความหลากหลาย (ตระกูลเดียวกัน 2 ชิ้น ×1.4 · ต่างกัน ×1.8 · 3 ชิ้น ×1.9 / ×2.3 / ×2.8) เวลาปรุง 4 วิต่อชิ้น มี 16 เมนูให้ค้นพบ
- **ของดิบ** ขายได้แต่ได้แค่ครึ่งราคา เพื่อให้การปรุงคุ้มกว่า
- **ลูกค้าต้องการ:** ทุก 5 นาที (เวลาเกม) มี 3 เมนูที่ราคา ×1.6 คนที่เล่นอยู่ปรุงตามได้ ส่วนแคชเชียร์อัตโนมัติจะขายเมนูที่ลูกค้าต้องการก่อน

### 13.2 บันไดอัปเกรด (ใช้เหรียญ)

| กลุ่ม | อัปเกรด | ผล |
|---|---|---|
| เก็บ | 🚁 โดรน | เก็บเข้ากระเป๋าให้เอง ช้ากว่ากดเอง ปรับเร็วขึ้นและเก็บทีละหลายชิ้นได้ |
| | 🎒 กระเป๋า / 📦 กองหน้าช่อง | ความจุ ถ้าเต็ม ขั้นก่อนหน้าก็หยุด |
| ปรุง | 🍲 หม้อเพิ่ม / 🔥 ปรุงไวขึ้น / 👨‍🍳 เชฟอัตโนมัติ | เชฟเลือกส่วนผสมคุ้มสุดจากกระเป๋าเอง |
| ขาย | 🧁 ตู้โชว์ / 💰 ราคาขาย / 🧾 แคชเชียร์ + ความเร็ว | |
| น้ำ | 💦 สปริงเกอร์ / ⛲ ปั๊ม / 🛢 ถัง | เปิดแล้วผลิตเร็ว ×2 ตราบที่ยังมีน้ำ **ตัวหายากกินน้ำมากกว่า** จึงต้องอัปเกรดปั๊มและถังตามระดับสัตว์ ถ้าน้ำหมดแค่เสียโบนัส ไม่มีโทษอื่น |

**เหตุผลของน้ำ:** เป็นเพดานที่ทำให้สัตว์ตำนานยังต้องมีระบบรองรับ ไม่ใช่แค่วางแล้วรวย (ตรงกับ "หลอด MAX" ที่ผู้เล่นยกตัวอย่าง) ผู้เล่นไม่ต้องป้อนอะไร ปั๊มเติมเอง สอดคล้องกับข้อตัดระบบป้อนอาหาร

### 13.3 สิ่งที่เกมข้างจอได้จากการเปลี่ยนนี้

- **ออฟไลน์มีความหมายขึ้น:** ตอนปิดเกม ระบบอัตโนมัติทำงานต่อ แต่ของที่ต้องกดเองจะค้างที่กองหน้าช่อง ผู้เล่นจึงเห็นประโยชน์ของโดรน/เชฟ/แคชเชียร์ชัดเจน
- **เล่นได้ 2 โหมด:** อยู่หน้าจอ = กดเองเร็วและตามลูกค้าได้ · วางข้างจอ = เปิดทิ้ง ระบบอัตโนมัติทำงานเอง
- ช่วงต้นเกมต้องกดเองมากกว่า ตั้งใจให้ผู้เล่นได้ "รู้สึก" ว่าอัตโนมัติคืออะไรก่อนซื้อ โดรนตัวแรกราคาถูก (🪙200)

### 13.4 ตัวเลขตั้งต้นและผลทดสอบด้วยบอท (ยังไม่ใช่ผลของผู้เล่นจริง)

- บอทกดเองช่วงต้นแล้วซื้ออัปเกรด: โดรนตัวแรกที่ ~3 นาที · เชฟ ~13 นาที · แคชเชียร์ ~15 นาที · สปริงเกอร์ ~17 นาที · ซื้ออัปเกรดทั้งหมดจนเต็มใน ~80 นาที
- รายได้หลังจากนั้นโตตามระดับสัตว์ (บอท 5 ชม. ~13K/นาที) **ข้อควรระวัง:** อัปเกรดเหรียญหมดเร็ว ส่วนที่เหลือต้องไปอยู่ที่ค่าผสม/สัตว์หายาก ต้องดูว่าผู้เล่นจริงรู้สึก "ไม่มีอะไรให้ซื้อ" ช่วงนั้นไหม

### 13.5 คำถามที่ต้องเล่นแล้วตัดสิน

1. การกดเก็บ → ปรุง → ขายเองช่วงต้นสนุกหรือน่าเบื่อ (ถ้าเบื่อ ลดขั้นหรือลดราคาโดรน)
2. ตัวคูณความหลากหลายทำให้ "คิดว่าจะใส่อะไรลงหม้อ" น่าสนใจพอไหม
3. น้ำ/สปริงเกอร์เพิ่มความลึกจริง หรือเป็นแค่อีกเมนูให้จัดการ
4. ลูกค้าต้องการเมนูไหน เปลี่ยนการตัดสินใจจริงไหม
5. ตอนบอทซื้ออัปเกรดครบแล้ว เกมยังมีเป้าหมายต่อไหม (ถ้าไม่ → ต้องเพิ่มชั้นอัปเกรดหรือย้ายถิ่นเร็วขึ้น)

## 14. ปรับ UX v0.3 — ลากวาง ลดเมนู และ "ทั้งหมด / ซ้ำ / อัตโนมัติ"

**ที่มา:** ผู้เล่นอยากให้เกมเป็นแนวลากวางเพื่อลดจำนวนเมนู และงานที่ต้องกดบ่อยให้มีปุ่ม "ทั้งหมด" หรือซื้อให้อัตโนมัติได้

### 14.1 โครงหน้าจอ

ยุบแท็บทั้ง 7 เหลือ **หน้าเดียว** วางกล่องสถานีไว้พร้อมกัน เพื่อให้ลากข้ามกล่องได้โดยไม่ต้องสลับหน้า:

`สถานะ → ฟาร์ม → ครัว → โรงผสม → สำรวจ → ช่องเก็บสัตว์ → [อัปเกรด | สมุด | ทดสอบ]`

เมนูรองเหลือ 3 ปุ่ม (ใช้ไม่บ่อย) ส่วนครัว โรงผสม สำรวจ ช่องเก็บ อยู่ในหน้าหลักทั้งหมด

### 14.2 ตารางการลากวาง

| ลากอะไร | ไปวางที่ | ผล |
|---|---|---|
| สัตว์ (ฟาร์ม/ช่องเก็บ) | ช่องฟาร์ม | วาง/สลับตำแหน่ง |
| สัตว์ในฟาร์ม | กล่องช่องเก็บ | เก็บเข้าช่องเก็บ |
| สัตว์ | กล่องโรงผสม | เป็นพ่อแม่ (ล็อกตัว ฟาร์มช่องนั้นหยุดผลิต) |
| สัตว์ (ช่องเก็บ) | กล่องสำรวจ | เป็นลูกเรือ |
| สัตว์ที่เตรียมไว้ใน โรงผสม/สำรวจ | ที่อื่น | ยกเลิกการเตรียม |
| สัตว์ | แถบ "ปล่อย" (โผล่ตอนลาก) | ปล่อยคืนธรรมชาติ |
| ผลผลิตในกระเป๋า | หม้อ | ใส่วัตถุดิบ |
| เมนูในตู้โชว์ | ช่องขาย | ขายทั้งชุดเมนูนั้น |

หลักการ: **ลากเป็นทางลัด ไม่ใช่ทางเดียว** ทุกอย่างยังแตะเลือกแล้วใช้ปุ่มได้ (สำหรับคนที่ไม่ถนัดลาก/ใช้ทัชสกรีน) ระหว่างลาก กล่องที่วางได้จะมีเส้นประเน้น และกล่องที่เมาส์อยู่จะสว่างขึ้น

### 14.3 ปุ่ม "ทั้งหมด / ซ้ำ" และระบบอัตโนมัติ

| งานที่ต้องทำบ่อย | ปุ่มทั้งหมด/ซ้ำ (ฟรี) | อัตโนมัติ (ซื้อด้วยเหรียญ) |
|---|---|---|
| เก็บผลผลิต | 🧺 เก็บทั้งหมด | 🚁 โดรน |
| ปรุง | ปรุงทุกหม้อให้ (สูตรคุ้มสุด) | 👨‍🍳 เชฟอัตโนมัติ |
| ขาย | ขายทั้งหมด | 🧾 แคชเชียร์ |
| รวมดาว | รวมดาวทั้งหมด | 🧹 จัดช่องเก็บอัตโนมัติ (🪙1,000) |
| ปล่อยตัวซ้ำ | ปล่อยตัวซ้ำ (เก็บ 3 ตัวดีสุดของแต่ละชนิด) | (รวมใน 🧹) |
| ผสม | ผสมซ้ำคู่เดิม | 🔁 ผสมซ้ำอัตโนมัติ (🪙3,000) |
| สำรวจ | ส่งซ้ำ (เลือกลูกเรือให้) | 🔁 สำรวจซ้ำอัตโนมัติ (🪙1,500) |

ระบบอัตโนมัติใหม่ใช้ตัวจาก **ช่องเก็บเท่านั้น** (ไม่ดึงสัตว์ในฟาร์มไปผสม/สำรวจเอง) และไม่ส่งตัวสีพิเศษหรือตัวที่รวมดาวแล้ว มีสวิตช์เปิด/ปิดในแต่ละกล่อง ถ้าผสมอัตโนมัติแต่เงินไม่พอจะรอ ไม่ติดลบ

### 14.4 สิ่งที่ต้องดูตอนเล่น

1. ลากแล้วรู้สึกลื่นหรือเปล่า (ระยะเริ่มลาก 8 พิกเซล) บนจอทัชสกรีนเลื่อนหน้าโดยแตะที่ตัวสัตว์ไม่ได้ ต้องเลื่อนจากพื้นที่ว่าง ซึ่งอาจต้องปรับ
2. หน้าเดียวยาวไปไหม (ต้องเลื่อนเยอะเมื่อลากไกล) ถ้ายาวเกินให้พิจารณาวางกล่องเป็น 2 คอลัมน์บนจอกว้าง
3. ปุ่ม "ทั้งหมด" ครอบคลุมงานที่กดซ้ำจริงหรือยัง
4. ระบบอัตโนมัติเรื่องผสม/สำรวจทำให้เกมตื้นลงไหม (เพราะผู้เล่นไม่ต้องเลือกอะไร) หรือทำให้เล่นข้างจอได้ดีขึ้นอย่างเดียว

## 15. เลย์เอาต์หน้าจอเดียว (v0.4)

**ที่มา:** ผู้เล่นอยากให้ทุกอย่างอยู่ในหน้าเดียวโดยไม่ต้องเลื่อน (สอดคล้องกับการวางหน้าต่างไว้ข้างจอ)

### 15.1 โครงหน้าจอ

จอกว้าง (กว้างตั้งแต่ ~820 พิกเซล) จัดเป็น 3 คอลัมน์ พอดีหน้าต่างขนาดเล็กสุด **~900×680** โดยไม่ต้องเลื่อนหน้า:

```
┌─────────────────────────────────────────────────────────┐
│ 🪙เหรียญ  ~รายได้/นาที   🎒กระเป๋า 💦น้ำ 🌿  [อัปเกรด][สมุด][ทดสอบ] │
│ ข้อความล่าสุด + คำแนะนำบรรทัดเดียว                          │
├───────────────────┬─────────────────┬───────────────────┤
│ ฟาร์ม 4×3          │ 🍲 ครัว          │ 💞 โรงผสม          │
│ 🧺เก็บทั้งหมด 💦    │ กระเป๋า→หม้อ     │ 🧭 สำรวจ           │
│ สัตว์ที่เลือก       │ ตู้โชว์ + ช่องขาย  │                   │
├───────────────────┴─────────────────┴───────────────────┤
│ 🧺 ช่องเก็บสัตว์ (แถวของช่องเล็ก เลื่อนภายในกล่องได้)        │
└─────────────────────────────────────────────────────────┘
```

- **อัปเกรด / สมุดภาพ / ห้องทดสอบ** เปิดเป็นหน้าต่างซ้อนทับ (ปิดด้วยปุ่มหรือคลิกพื้นหลัง) ไม่ทำให้หน้าหลักยาวขึ้น ตำแหน่งเลื่อนในหน้าต่างไม่หายตอนเกมอัปเดต
- ช่องสัตว์ในช่องเก็บ/โรงผสม/ลูกเรือเป็นแบบเล็ก (อีโมจิ + ดาว + ไอคอนบทบาท) ชื่อดูได้จากการชี้ (tooltip) หรือเลือกแล้วดูแถบรายละเอียด
- ส่วนที่ยาวได้ (ตู้โชว์ ช่องเก็บ) เลื่อนภายในกล่อง ไม่ดันทั้งหน้า

### 15.2 ข้อจำกัดที่ยังมี

- **หน้าต่างแคบแนวตั้ง (~420 พิกเซล) ยังต้องเลื่อน** เพราะกล่องทั้งหมดไม่พอดีแนวตั้ง (ประมาณ 1,450 พิกเซล) ต้องเลือกว่าจะทำเลย์เอาต์แนวตั้งแยก (เช่น พับครัว/โรงผสม/สำรวจเป็นแถบ) หรือกำหนดให้หน้าต่างข้างจอเป็นแนวนอนอย่างเดียว
- ถ้าหน้าต่างเตี้ยกว่า ~680 พิกเซล ส่วนในกล่องจะเริ่มเลื่อน

### 15.3 คำถามสำหรับ Unity เวอร์ชันจริง

1. หน้าต่างข้างจอจริงควรเป็นแนวนอน (~900×680) หรือแนวตั้ง? ตัดสินใจก่อนเริ่มออกแบบ UI จริง เพราะเลย์เอาต์ต่างกันมาก
2. ถ้าเลือกแนวตั้ง ต้องพิจารณาโหมดแถบเล็ก (mini mode) ที่โชว์เฉพาะรายได้และสิ่งที่เสร็จแล้ว (ตามข้อ 8.3) และเปิดกล่องเต็มเมื่อคลิก
