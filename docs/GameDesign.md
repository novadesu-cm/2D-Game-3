## 0. สถานะเอกสาร

**ตัดออกจากการออกแบบเดิม**

| ระบบที่ตัด | เหตุผล |
|---|---|
| ระบบผู้พิทักษ์ (Guardian) | ผู้เล่นสั่งตัด |
| การป้อนอาหาร / ต้องกลับมากดเลี้ยง | ผู้เล่นสั่งตัด และขัดกับการเล่นข้างจอ |
| ทุกอย่างที่ "ลงโทษ" ตอนผู้เล่นไม่อยู่ | สัตว์ไม่หิว ไม่ป่วย ไม่ตาย ไม่หนีไป |

ข้อกำหนดข้อนี้ใช้กับทุกฟีเจอร์ที่เพิ่มในอนาคตด้วย: **ห้ามมีระบบที่บังคับให้ผู้เล่นต้องกลับมากดภายในเวลาที่กำหนด**

**ข้อกำหนดจากผู้เล่น (ต้นฉบับ)**

1. เกมแนว Idle บรรยากาศฟาร์ม แต่เป็นการเลี้ยงสัตว์
2. ผสมสัตว์เพื่อหาสัตว์ชนิดใหม่
3. สัตว์ที่วางลงช่องต้อง **มีประโยชน์** อย่างใดอย่างหนึ่ง
4. สัตว์ที่เกินจำนวนช่อง ต้อง **เก็บ/ดอง** ไว้ใน "ช่องเก็บสัตว์" ได้
5. เล่นข้างจอ (วางหน้าต่างเล็กๆ ไว้ข้างงานอื่น)
6. ถ้าข้อกำหนดข้อไหนขัดกับการเป็นเกมที่ดี ให้เอาเกมที่ดีก่อน

## 1. ข้อกำหนดที่ถูกปรับเพื่อให้เป็นเกมที่ดี

ตามข้อ 6 ผมไล่ตรวจแล้ว ข้อที่ต้องปรับหรือเติมมีดังนี้ ถ้าไม่เห็นด้วยข้อไหนบอกได้ เพราะแต่ละข้อแก้แยกกันได้

| # | ข้อกำหนดเดิม | ปัญหาถ้าทำตรงๆ | สิ่งที่ออกแบบจริง |
|---|---|---|---|
| A | "สัตว์ในช่องต้องมีประโยชน์" | ถ้าทุกตัวแค่ "ผลิตเหรียญ" ผู้เล่นไม่มีการตัดสินใจ เอาตัวแรงสุดใส่ก็จบ | แบ่ง **5 บทบาท** (ผลิต / หนุนข้างเคียง / เร่งผสม / เร่งสำรวจ / เฝ้าฟาร์ม) ช่องมีจำกัด ใส่บทบาทหนึ่งต้องเสียอีกบทบาทหนึ่ง และมี **การวางตำแหน่งติดกัน** ทำให้ตำแหน่งมีผล |
| B | "สัตว์เกินให้ดองไว้" | ช่องเก็บที่เก็บเฉยๆ กลายเป็นแค่ตัวนับที่เต็มแล้วน่ารำคาญ | ช่องเก็บเป็น **คลังพ่อแม่พันธุ์ + คลังลูกเรือสำรวจ + วัตถุดิบรวมดาว** สัตว์เก่าอ่อนแรงก็ไม่ไร้ค่า (ดูข้อ 5.3) |
| C | ผสมแล้วสุ่มหาสัตว์ใหม่ | ถ้าต้องไล่ลองคู่แบบมั่วๆ และแต่ละคู่ต้องรอเวลา จะรู้สึกเหมือนเสียเวลา ไม่ใช่การค้นพบ | มี **ระบบใบ้สูตร** และ **ตัวนับกันซวย (pity)** ผู้เล่นเดาสูตรได้อย่างมีเหตุผล ไม่ต้องสุ่มบริสุทธิ์ |
| D | เล่นข้างจอ | แอนิเมชันหนักๆ หรือเหตุการณ์ที่ต้องรีบกด ใช้ไม่ได้ | ทุกการดูแลใช้เวลาไม่เกิน ~30 วินาที ไม่มีสถานะแพ้ ไม่มีกิจกรรมจับเวลาที่พลาดแล้วเสียของ และกินแรงเครื่องต่ำ (ดูข้อ 8) |
| E | ตัดการป้อนอาหาร | เกม Idle ที่ไม่มีเหตุผลให้ "กลับมา" จะจืด | เหตุผลที่กลับมาเป็นเรื่องบวก ไม่ใช่บังคับ: ไข่ฟัก, สำรวจเสร็จ, ปลดล็อกสูตร, คิวเลือกวางสัตว์ใหม่ ปล่อยทิ้งไว้ก็ไม่เสียอะไร |
| F | ไม่ได้ระบุ | ไม่มีเป้าหมายระยะยาว เล่นแล้วตันเร็ว | **สมุดภาพ (Codex)** เป็นเป้าหมายหลัก และ **ย้ายถิ่น (Migration/Prestige)** เป็นวงรอบระยะยาว (เฟส 2) |

## 2. เสาหลักของเกม (Design Pillars)

1. **เปิดทิ้งไว้ก็สนุก** — เกมเดินเองทุกอย่าง การกลับมาดูคือรางวัล ไม่ใช่หน้าที่
2. **ทุกตัวมีที่ทางของมัน** — ไม่มีสัตว์ที่ "ได้มาแล้วไร้ประโยชน์ทันที"
3. **ค้นพบ ไม่ใช่สุ่มเปล่า** — การผสมคือการไขปริศนาสูตร มีเบาะแสให้
4. **ไม่มีการลงโทษ** — ไม่มีหาย ไม่มีตาย ไม่มีหมดเวลา ไม่มีล็อกอินรายวัน
5. **อ่านออกในหน้าต่างเล็ก** — เห็นสถานะทั้งหมดได้ในพื้นที่ ~360×480 พิกเซล

## 3. วงจรการเล่น

### 3.1 วงจรหลัก (ระยะยาว)

```
        ┌─────────── ได้ "เหรียญ" ต่อวินาที ───────────┐
        ▼                                              │
   [ฟาร์ม: สัตว์ในช่อง]  ──ซื้อช่อง/อัปเกรด/จ่ายค่าผสม──►  [เหรียญ]
        ▲                                              │
        │ เลือกสัตว์ที่เก่งขึ้นมาวาง                     │
        │                                              ▼
   [ช่องเก็บสัตว์] ◄── ไข่ฟัก ◄── [โรงผสม] ◄──── พ่อแม่จากฟาร์ม/ช่องเก็บ
        ▲                                              
        └────── สัตว์ป่าใหม่ ◄── [สำรวจ] ◄── ลูกเรือจากช่องเก็บ
```

### 3.2 วงจรการเข้ามาดู (ครั้งละ 10–30 วินาที ทุก 5–20 นาที)

1. ดูว่ามีอะไรเสร็จ (ไข่ฟัก / สำรวจกลับมา) → เก็บของ
2. ตัดสินใจ 1–3 อย่าง: สัตว์ใหม่ตัวนี้ **ลงช่องฟาร์ม** หรือ **เข้าช่องเก็บ**?
3. เริ่มผสมคู่ใหม่ / ส่งสำรวจรอบใหม่ (มีปุ่ม "ทำซ้ำรอบที่แล้ว" กดเดียวจบ)
4. ใช้เหรียญซื้ออะไรสักอย่าง แล้วปล่อยเกมไว้

## 4. ระบบฟาร์มและสัตว์

### 4.1 สัตว์

คุณสมบัติของสัตว์หนึ่งตัว:

| ฟิลด์ | คำอธิบาย |
|---|---|
| ชนิด (Species) | 27 ชนิดในเวอร์ชันแรก (ข้อ 6) |
| ระดับความหายาก | สามัญ / พิเศษ / หายาก / มหากาพย์ / ตำนาน |
| บทบาท | 1 อย่าง (ตำนานมี 2 อย่าง) ดูข้อ 4.2 |
| ดาว ★ | 1–3 เพิ่มได้โดยรวมสัตว์ชนิดเดียวกัน (ข้อ 5.3) |
| สีพิเศษ (Variant) | โอกาสน้อยตอนฟักไข่ แรงขึ้น ×1.5 และมีช่องในสมุดภาพแยก |

**ไม่มีเลเวลต่อตัว ไม่มีการป้อน ไม่มีค่าความสุข** ความแรงมาจาก ความหายาก × ดาว × สีพิเศษ × ตำแหน่งในฟาร์ม เท่านั้น (ลดงานกดซ้ำๆ ที่ไม่เหมาะกับการเล่นข้างจอ)

### 4.2 บทบาท (นี่คือ "ประโยชน์" ของสัตว์ในช่อง)

| บทบาท | ผลตอนวางในช่องฟาร์ม | ผลิตเหรียญเอง? |
|---|---|---|
| 🪙 ผู้ผลิต (Producer) | ผลิตเหรียญต่อวินาที | ผลิตเอง |
| 📣 ผู้หนุน (Booster) | เพิ่ม % ให้ช่อง **บน/ล่าง/ซ้าย/ขวา** ที่ติดกัน | ไม่ผลิตเอง |
| 💞 ผู้เร่งผสม (Breeder) | ลดเวลาผสมทุกคู่ และเพิ่มโอกาสสีพิเศษ (รวมกันทั้งฟาร์ม) | ไม่ผลิตเอง |
| 🧭 ผู้เร่งสำรวจ (Scout) | ลดเวลาสำรวจ และเพิ่มคุณภาพของที่ได้ (รวมกันทั้งฟาร์ม) | ไม่ผลิตเอง |
| 🏠 ผู้เฝ้าฟาร์ม (Keeper) | เพิ่มเพดานเวลาออฟไลน์ และเพิ่มความจุช่องเก็บ | ไม่ผลิตเอง |

สัตว์ **ตำนาน** มี 2 บทบาทในตัวเดียว จึงคุ้มกับที่ต้องใช้เวลาไต่มานาน

**ทำไมถึงเป็น "การตัดสินใจ" จริงๆ:** ช่องฟาร์มเริ่มที่ 3 ช่อง ขยายได้ถึง 12 ช่อง (กริด 4×3) ผู้เล่นต้องแลกกัน เช่น ใส่ผู้ผลิตให้หมดเพื่อเงินเร็ว หรือแบ่งช่องให้ผู้เร่งผสมเพื่อให้ไต่ระดับหายากเร็วขึ้น และตำแหน่งผู้หนุนต้องไปอยู่ข้างผู้ผลิตที่แรงที่สุด

### 4.3 ช่องฟาร์ม

- กริด 4 คอลัมน์ × 3 แถว ปลดล็อกทีละช่องตามลำดับคงที่ (ซ้ายบน → ขวาล่าง)
- ช่องที่ยังไม่ซื้อแสดงเป็นเงา พร้อมราคา
- ย้ายสัตว์ระหว่างช่องฟาร์มกับช่องเก็บได้ทันที ไม่มีค่าใช้จ่าย ไม่มีคูลดาวน์
- สูตรผลผลิตของผู้ผลิตหนึ่งตัว:

```
เหรียญ/วิ  = ฐานตามความหายาก × ตัวคูณดาว × ตัวคูณสีพิเศษ
             × (1 + ผลรวม % จากผู้หนุนข้างเคียง)
             × ตัวคูณทั้งฟาร์ม (อัปเกรด + ย้ายถิ่น)
```

## 5. ระบบรอง

### 5.1 โรงผสม (Nursery)

- เริ่มต้นมี 1 ช่องผสม ปลดล็อกเพิ่มได้ถึง 3 (ใช้ "แก่นธรรมชาติ")
- วางพ่อแม่ 2 ตัว จ่ายเหรียญ รอเวลา แล้วได้ **ไข่ 1 ฟอง** ไปไว้ในช่องเก็บ (ฟักเองอัตโนมัติ)
- **พ่อแม่ไม่ถูกใช้หมด** แต่ระหว่างผสมจะถูกล็อก ถ้าดึงมาจากช่องฟาร์ม ช่องนั้นจะว่างและหยุดทำงานจนกว่าจะเสร็จ (ราคาของการเลือก) ถ้าดึงจากช่องเก็บ ไม่เสียอะไร
- ผลลัพธ์การผสม (ไม่สนลำดับพ่อแม่):

| คู่พ่อแม่ | ผลลัพธ์ |
|---|---|
| ตรงสูตร | สัตว์ตามสูตร (ข้อ 6.2) |
| ชนิดเดียวกัน | ชนิดเดิมแน่นอน (ใช้หาตัวซ้ำไปรวมดาว) |
| ไม่ตรงสูตร ชนิดต่างกัน | สุ่มเป็นชนิดของพ่อหรือแม่ (50/50) |
| ทุกกรณี | โอกาสออก **สีพิเศษ** 5% (+ ผู้เร่งผสม) |

- สูตรที่ลองแล้วไม่ตรงจะบันทึกใน "ประวัติการลอง" เพื่อไม่ให้ผู้เล่นต้องจำเอง
- เวลาผสมตามความหายากของลูก: สามัญ 20 วิ · พิเศษ 2 นาที · หายาก 10 นาที · มหากาพย์ 1 ชม. · ตำนาน 4 ชม. (ผู้เร่งผสมลดได้สูงสุด −60%)

**ระบบใบ้สูตร (ลดความมั่ว):**
- เมื่อผู้เล่นมีพ่อหรือแม่ตัวหนึ่งของสูตร สมุดภาพจะแสดง "เงาสัตว์ + ใช้ [ชื่อสัตว์ที่ตัวเองมี] + ?" ให้เห็น
- การสำรวจมีโอกาสได้ "เบาะแสสูตร" เปิดสูตรเต็มให้ 1 สูตร

### 5.2 การสำรวจ (Expedition)

- ส่ง **ลูกเรือ 1–3 ตัว จากช่องเก็บ** ไปโซนต่างๆ ลูกเรือกลับมาพร้อมของรางวัล ตอนอยู่ข้างนอกจะใช้ทำอย่างอื่นไม่ได้ (ทำให้สัตว์ในช่องเก็บมีงานทำ)
- โซนและเงื่อนไขปลดล็อก (นับจำนวนชนิดที่ค้นพบในสมุดภาพ):

| โซน | ปลดล็อกเมื่อค้นพบ | ได้อะไร | เวลา |
|---|---|---|---|
| 1 ทุ่งหญ้า | 0 | สัตว์ป่าสามัญ, เหรียญ | 30 วิ (สอนเล่น) – 5 นาที |
| 2 ลำธาร | 6 | สามัญ + โอกาสต่ำที่จะเจอระดับพิเศษ, เบาะแสสูตร | 30 นาที |
| 3 ป่าลึก | 12 | ถึงระดับหายาก, แก่นธรรมชาติ | 2 ชม. |
| 4 ภูผาเมฆ | 18 | ถึงระดับมหากาพย์ | 6 ชม. |
| 5 ถ้ำนาคา | 24 | ถึงระดับตำนาน (เจอยากมาก) | 12 ชม. |

- ของรางวัลที่ได้: **ไข่ลึกลับ** (สัตว์ป่าชนิดที่ยังไม่มี มีน้ำหนักสูงกว่า) · เหรียญก้อนใหญ่ (เทียบเท่ารายได้ N นาที) · เบาะแสสูตร · แก่นธรรมชาติ
- ความหายากรวมของลูกเรือและจำนวนลูกเรือเพิ่มคุณภาพของที่ได้ ผู้เร่งสำรวจในฟาร์มช่วยลดเวลา
- **กันซวย (pity):** ถ้าไม่ได้ของระดับสูงสุดของโซนติดกัน N รอบ รอบถัดไปการันตี
- ไม่มีความเสี่ยงที่ลูกเรือจะหายหรือบาดเจ็บ

### 5.3 ช่องเก็บสัตว์ ("ตู้ดอง")

"ดอง" ตามคำที่ผู้เล่นใช้ ผมตีความว่า **เก็บไว้ก่อนโดยไม่เสีย** ถ้าอยากให้ "ดอง" หมายถึงสัตว์เก็บนานแล้วได้โบนัสด้วย บอกได้ ดูข้อ 11

- ความจุเริ่ม 12 ตัว ขยายด้วยแก่นธรรมชาติและผู้เฝ้าฟาร์ม (สูงสุด ~100)
- สัตว์ในช่องเก็บ **ไม่ผลิต ไม่ทำงานบทบาท** (ไม่งั้นช่องฟาร์มไร้ความหมาย) แต่ใช้ได้ 4 ทาง:
  1. **เป็นพ่อแม่พันธุ์** ส่งเข้าโรงผสมโดยไม่ทำให้ฟาร์มเสียรายได้
  2. **เป็นลูกเรือสำรวจ**
  3. **รวมดาว:** ชนิดเดียวกัน 3 ตัวที่ดาวเท่ากัน → 1 ตัวดาว +1 (สูงสุด ★3 ในเวอร์ชันแรก) ดาวคือที่ระบายตัวซ้ำ
  4. **ปล่อยคืนธรรมชาติ:** แลกเป็นเหรียญนิดหน่อย + **แก่นธรรมชาติ** (ตามความหายาก) ใช้ปลดล็อกถาวร
- **ช่องเก็บเต็ม ไม่ทำให้อะไรหาย** — ไข่ที่ฟักแล้วจะค้างรอในโรงผสมจนกว่าจะมีที่ว่าง ผู้เล่นเลือกปล่อย/รวมดาวสัตว์ตัวเก่าได้ตอนนั้น
- มีปุ่มจัดเรียง/กรอง ตามบทบาทและความหายาก และปุ่ม "ปล่อยตัวซ้ำที่ไม่จำเป็น" ที่เหลือสัตว์ที่ยังขาดดาวอยู่ไว้

### 5.4 เศรษฐกิจ

มีเงินตราเพียง 2 อย่าง (น้อยเพื่อให้อ่านง่ายในหน้าต่างเล็ก):

| สกุล | ได้จาก | ใช้ซื้อ |
|---|---|---|
| 🪙 เหรียญ | ผู้ผลิต, สำรวจ, ปล่อยสัตว์ | ช่องฟาร์ม, ค่าผสม, อัปเกรดฟาร์ม (ตัวคูณทั้งฟาร์ม) |
| 🌿 แก่นธรรมชาติ | ปล่อยสัตว์, สำรวจโซนสูง | ช่องผสม/ช่องสำรวจเพิ่ม, ขยายช่องเก็บ, ปุ่ม "ทำซ้ำ/เก็บอัตโนมัติ", ย้ายถิ่น (เฟส 2) |

ไม่มีเงินจริงในเวอร์ชันนี้ (ดูข้อ 11)

### 5.5 ออฟไลน์

- เหรียญสะสมได้ตอนปิดเกม เพดานเริ่ม **4 ชม.** เพิ่มด้วยผู้เฝ้าฟาร์ม (สูงสุด 24 ชม.)
- ไข่และการสำรวจนับเวลาจริง ฟักและเสร็จตอนปิดเกมได้
- เปิดเกมขึ้นมามีหน้าสรุป "ระหว่างที่ไม่อยู่" (เหรียญที่ได้, ไข่ที่ฟัก, สำรวจที่เสร็จ)

### 5.6 สมุดภาพ (Codex) และเป้าหมาย

- 27 ชนิด × (ปกติ / สีพิเศษ) พร้อมเงาสัตว์ของที่ยังไม่เจอ และสูตรที่ค้นพบแล้ว
- ใช้เป็นเงื่อนไขปลดล็อกโซนสำรวจ และเป็นเป้าหมายระยะยาวหลัก
- ภารกิจสั้นๆ แบบไม่จับเวลา ("มีผู้หนุน 2 ตัวติดกัน", "ผสมสูตรแรกสำเร็จ") ให้เป้าหมายทีละขั้นระหว่างนำทางเกม

### 5.7 ย้ายถิ่น (Prestige) — เฟส 2

รีเซ็ตเหรียญ ช่องฟาร์ม และอัปเกรดฟาร์ม แลกกับ "ตัวคูณถาวร" **เก็บ: สมุดภาพ, สูตรที่ค้นพบ, ช่องเก็บและสัตว์ในนั้น, ช่องผสม/สำรวจที่ซื้อ** ไว้ รายละเอียดจะออกแบบหลังจบการทดสอบเฟส 1

## 8. การเล่นข้างจอ — UX และเทคนิค

### 8.1 หลักการ

- ทุกอย่างอ่านออกได้ในแวบเดียว ไม่ต้องเลื่อนหน้า
- แจ้งเตือนแบบเบา: ป้ายแดงบนปุ่ม + เสียงเตือนเบาๆ (ปิดได้) ไม่มีป๊อปอัปบังหน้าจอ
- เสียงปิดเป็นค่าเริ่มต้น
- ไม่มีสิ่งใดต้องพลาด ไม่มีกิจกรรมจำกัดเวลา

### 8.3 โหมดแถบเล็ก (Mini mode)

ย่อเหลือแถบ ~360×120 เห็นเฉพาะรายได้ ไข่/สำรวจเสร็จหรือยัง และมีป้ายแจ้งเตือน เหมาะวางไว้ขอบจอตอนทำงานอื่น

### 8.4 ฟีเจอร์หน้าต่าง

| ฟีเจอร์ | หมายเหตุ |
|---|---|
| อยู่บนสุดเสมอ (Always on top) | ปุ่มสลับ |
| ลากย้ายได้, ปรับขนาดได้, จำตำแหน่ง | |
| ความโปร่งใสปรับได้ | ตอนเมาส์ไม่อยู่บนหน้าต่าง |
| เล่นต่อเมื่อไม่ได้โฟกัส | `Application.runInBackground = true` |
| ลดเฟรมเรตเมื่อไม่โฟกัส | โฟกัส 30 fps / ไม่โฟกัส 10 fps / ย่อ 2 fps (คำนวณเกมด้วยเวลาจริง ไม่ผูกกับเฟรม) |

### 8.5 หมายเหตุสถาปัตยกรรม (Unity 6)

- **ข้อมูลเป็น ScriptableObject:** `SpeciesData`, `RecipeData`, `ZoneData`, `UpgradeData` — เพิ่มสัตว์โดยไม่ต้องแก้โค้ด
- **แยก simulation ออกจาก view:** คำนวณด้วยเวลา UTC และสูตรปิด (`เหรียญ += อัตรา × Δt`) ใช้ตัวเดียวกันทั้งตอนเล่นและตอนคำนวณออฟไลน์
- **เซฟ:** JSON ในเครื่อง มีเลขเวอร์ชัน เซฟอัตโนมัติทุก 30 วินาทีและตอนปิดเกม เขียนแบบ atomic (เขียนไฟล์ชั่วคราวแล้วเปลี่ยนชื่อ)
- **ตัวเลข:** ใช้ `double` พร้อมตัวจัดรูปแบบ (K, M, B, …) พอสำหรับเฟส 1 ถ้าตัวคูณย้ายถิ่นทำให้เกินช่วง ค่อยย้ายไปแบบ BigDouble
- **อัปเดต UI เมื่อข้อมูลเปลี่ยนเท่านั้น** (event-driven) ไม่ poll ทุกเฟรม
- **ฟังก์ชันหน้าต่าง (always-on-top, ไร้ขอบ, โปร่งใส):** ใช้ Win32 API (`user32.dll` — `SetWindowPos` ฯลฯ) ได้เฉพาะ **Windows** บนแพลตฟอร์มอื่นต้องใช้วิธีของมันเอง → ต้องยืนยันแพลตฟอร์มเป้าหมาย (ข้อ 11)
- **สไตล์ภาพ (เสนอ):** สีพาสเทลนุ่มๆ ตัวการ์ตูนเรียบๆ อ่านออกที่ขนาด ~48 พิกเซลต่อตัว แอนิเมชันกระดิกเบาๆ ไม่กี่เฟรม

## 13. ปรับดีไซน์ v0.2 — เพิ่มความลึกด้วยสายพานผลผลิต

**ที่มา:** ผู้เล่นรู้สึกว่าเวอร์ชันแรกตื้น (สัตว์ผลิตเหรียญตรงๆ) ต้องการวงจรแบบเกมปลูกผักใน Roblox: เก็บ → ปรุง → ขาย แล้วใช้เงินปลดล็อกระบบอัตโนมัติทีละชั้น

**หลักการที่ยืมมา:** ความลึกของเกมแนวนี้ไม่ได้มาจากการเดิน แต่มาจาก **บันไดทำเองเร็ว → ปลดล็อกอัตโนมัติที่ช้ากว่า → อัปเกรดให้เร็วขึ้น** และ **คอขวดที่ย้ายไปเรื่อยๆ** (ผลิตเร็วกว่าที่โดรนเก็บทัน → กระเป๋าเต็ม → หม้อไม่พอ → ตู้โชว์เต็ม ฯลฯ)

**ที่ไม่เอามา:** การเดินไปมาในแผนที่ ขัดกับเกมข้างจอ (หน้าต่างเล็ก ต้องมีส่วนที่ทำเองได้แค่กดปุ่ม) จึงใช้ปุ่มสถานีแทน ส่วนความรู้สึก "ทำเองเร็วกว่า" ยังอยู่ เพราะตอนอยู่หน้าจอกดเก็บ/ปรุง/ขายเองได้ทันที ขณะที่ระบบอัตโนมัติทำงานตามจังหวะของมัน

### 13.1 สายพานผลผลิต

```
สัตว์ผู้ผลิต → (แถบผลิตเต็ม) → กองหน้าช่อง → [เก็บเอง / โดรน] → กระเป๋า
   → [โยนลงหม้อ 2–3 ชิ้น / เชฟอัตโนมัติ] → ตู้โชว์ → [ขายเอง / แคชเชียร์] → เหรียญ
```

- **ผู้ผลิต** ไม่ให้เหรียญแล้ว แต่ให้ **ผลผลิต** 3 ตระกูล: 🥚 ไข่ (ไก่ เป็ด ห่าน) · 🥛 นม (แกะ อัลปาก้า แกะขนทอง) · 🌰 ของป่า (บีเวอร์ กวางทองคำ กินรี)
- ผลผลิตสะสมเป็น **กองหน้าช่อง** (เริ่มที่ 3 ชิ้น) กองเต็มแล้วสัตว์ **หยุดผลิต** (ไม่มีโทษอื่น) นี่คือเหตุผลที่ต้องเก็บ หรือมีโดรน
- มูลค่าผลผลิตต่อชิ้น: 6 / 24 / 96 / 384 / 1,536 ตามระดับความหายาก · ความเร็วผลิต 8–16 วิต่อชิ้น (ดาวและสีพิเศษเพิ่มความเร็ว ผู้หนุนเพิ่มความเร็วช่องข้างเคียง)
- **หม้อ:** ใส่ 2–3 ชิ้น มูลค่าอาหาร = ผลรวมมูลค่าวัตถุดิบ × ตัวคูณความหลากหลาย (ตระกูลเดียวกัน 2 ชิ้น ×1.4 · ต่างกัน ×1.8 · 3 ชิ้น ×1.9 / ×2.3 / ×2.8) เวลาปรุง 4 วิต่อชิ้น มี 16 เมนูให้ค้นพบ
- **ของดิบ** ขายได้แต่ได้แค่ครึ่งราคา เพื่อให้การปรุงคุ้มกว่า
- **ลูกค้าต้องการ:** ทุก 5 นาที (เวลาเกม) มี 3 เมนูที่ราคา ×1.6 คนที่เล่นอยู่ปรุงตามได้ ส่วนแคชเชียร์อัตโนมัติจะขายเมนูที่ลูกค้าต้องการก่อน

### 13.2 บันไดอัปเกรด (ใช้เหรียญ)

| กลุ่ม | อัปเกรด | ผล |
|---|---|---|
| เก็บ | 🚁 โดรน | เก็บเข้ากระเป๋าให้เอง ช้ากว่ากดเอง ปรับเร็วขึ้นและเก็บทีละหลายชิ้นได้ |
| | 🎒 กระเป๋า / 📦 กองหน้าช่อง | ความจุ ถ้าเต็ม ขั้นก่อนหน้าก็หยุด |
| ปรุง | 🍲 หม้อเพิ่ม / 🔥 ปรุงไวขึ้น / 👨‍🍳 เชฟอัตโนมัติ | เชฟเลือกส่วนผสมคุ้มสุดจากกระเป๋าเอง |
| ขาย | 🧁 ตู้โชว์ / 💰 ราคาขาย / 🧾 แคชเชียร์ + ความเร็ว | |
| น้ำ | 💦 สปริงเกอร์ / ⛲ ปั๊ม / 🛢 ถัง | เปิดแล้วผลิตเร็ว ×2 ตราบที่ยังมีน้ำ **ตัวหายากกินน้ำมากกว่า** จึงต้องอัปเกรดปั๊มและถังตามระดับสัตว์ ถ้าน้ำหมดแค่เสียโบนัส ไม่มีโทษอื่น |

**เหตุผลของน้ำ:** เป็นเพดานที่ทำให้สัตว์ตำนานยังต้องมีระบบรองรับ ไม่ใช่แค่วางแล้วรวย (ตรงกับ "หลอด MAX" ที่ผู้เล่นยกตัวอย่าง) ผู้เล่นไม่ต้องป้อนอะไร ปั๊มเติมเอง สอดคล้องกับข้อตัดระบบป้อนอาหาร

### 13.3 สิ่งที่เกมข้างจอได้จากการเปลี่ยนนี้

- **ออฟไลน์มีความหมายขึ้น:** ตอนปิดเกม ระบบอัตโนมัติทำงานต่อ แต่ของที่ต้องกดเองจะค้างที่กองหน้าช่อง ผู้เล่นจึงเห็นประโยชน์ของโดรน/เชฟ/แคชเชียร์ชัดเจน
- **เล่นได้ 2 โหมด:** อยู่หน้าจอ = กดเองเร็วและตามลูกค้าได้ · วางข้างจอ = เปิดทิ้ง ระบบอัตโนมัติทำงานเอง
- ช่วงต้นเกมต้องกดเองมากกว่า ตั้งใจให้ผู้เล่นได้ "รู้สึก" ว่าอัตโนมัติคืออะไรก่อนซื้อ โดรนตัวแรกราคาถูก (🪙200)

### 13.4 ตัวเลขตั้งต้นและผลทดสอบด้วยบอท (ยังไม่ใช่ผลของผู้เล่นจริง)

- บอทกดเองช่วงต้นแล้วซื้ออัปเกรด: โดรนตัวแรกที่ ~3 นาที · เชฟ ~13 นาที · แคชเชียร์ ~15 นาที · สปริงเกอร์ ~17 นาที · ซื้ออัปเกรดทั้งหมดจนเต็มใน ~80 นาที
- รายได้หลังจากนั้นโตตามระดับสัตว์ (บอท 5 ชม. ~13K/นาที) **ข้อควรระวัง:** อัปเกรดเหรียญหมดเร็ว ส่วนที่เหลือต้องไปอยู่ที่ค่าผสม/สัตว์หายาก ต้องดูว่าผู้เล่นจริงรู้สึก "ไม่มีอะไรให้ซื้อ" ช่วงนั้นไหม

### 13.5 คำถามที่ต้องเล่นแล้วตัดสิน

1. การกดเก็บ → ปรุง → ขายเองช่วงต้นสนุกหรือน่าเบื่อ (ถ้าเบื่อ ลดขั้นหรือลดราคาโดรน)
2. ตัวคูณความหลากหลายทำให้ "คิดว่าจะใส่อะไรลงหม้อ" น่าสนใจพอไหม
3. น้ำ/สปริงเกอร์เพิ่มความลึกจริง หรือเป็นแค่อีกเมนูให้จัดการ
4. ลูกค้าต้องการเมนูไหน เปลี่ยนการตัดสินใจจริงไหม
5. ตอนบอทซื้ออัปเกรดครบแล้ว เกมยังมีเป้าหมายต่อไหม (ถ้าไม่ → ต้องเพิ่มชั้นอัปเกรดหรือย้ายถิ่นเร็วขึ้น)

## 14. ปรับ UX v0.3 — ลากวาง ลดเมนู และ "ทั้งหมด / ซ้ำ / อัตโนมัติ"

**ที่มา:** ผู้เล่นอยากให้เกมเป็นแนวลากวางเพื่อลดจำนวนเมนู และงานที่ต้องกดบ่อยให้มีปุ่ม "ทั้งหมด" หรือซื้อให้อัตโนมัติได้

### 14.1 โครงหน้าจอ

ยุบแท็บทั้ง 7 เหลือ **หน้าเดียว** วางกล่องสถานีไว้พร้อมกัน เพื่อให้ลากข้ามกล่องได้โดยไม่ต้องสลับหน้า:

`สถานะ → ฟาร์ม → ครัว → โรงผสม → สำรวจ → ช่องเก็บสัตว์ → [อัปเกรด | สมุด | ทดสอบ]`

เมนูรองเหลือ 3 ปุ่ม (ใช้ไม่บ่อย) ส่วนครัว โรงผสม สำรวจ ช่องเก็บ อยู่ในหน้าหลักทั้งหมด

### 14.2 ตารางการลากวาง

| ลากอะไร | ไปวางที่ | ผล |
|---|---|---|
| สัตว์ (ฟาร์ม/ช่องเก็บ) | ช่องฟาร์ม | วาง/สลับตำแหน่ง |
| สัตว์ในฟาร์ม | กล่องช่องเก็บ | เก็บเข้าช่องเก็บ |
| สัตว์ | กล่องโรงผสม | เป็นพ่อแม่ (ล็อกตัว ฟาร์มช่องนั้นหยุดผลิต) |
| สัตว์ (ช่องเก็บ) | กล่องสำรวจ | เป็นลูกเรือ |
| สัตว์ที่เตรียมไว้ใน โรงผสม/สำรวจ | ที่อื่น | ยกเลิกการเตรียม |
| สัตว์ | แถบ "ปล่อย" (โผล่ตอนลาก) | ปล่อยคืนธรรมชาติ |
| ผลผลิตในกระเป๋า | หม้อ | ใส่วัตถุดิบ |
| เมนูในตู้โชว์ | ช่องขาย | ขายทั้งชุดเมนูนั้น |

หลักการ: **ลากเป็นทางลัด ไม่ใช่ทางเดียว** ทุกอย่างยังแตะเลือกแล้วใช้ปุ่มได้ (สำหรับคนที่ไม่ถนัดลาก/ใช้ทัชสกรีน) ระหว่างลาก กล่องที่วางได้จะมีเส้นประเน้น และกล่องที่เมาส์อยู่จะสว่างขึ้น

### 14.3 ปุ่ม "ทั้งหมด / ซ้ำ" และระบบอัตโนมัติ

| งานที่ต้องทำบ่อย | ปุ่มทั้งหมด/ซ้ำ (ฟรี) | อัตโนมัติ (ซื้อด้วยเหรียญ) |
|---|---|---|
| เก็บผลผลิต | 🧺 เก็บทั้งหมด | 🚁 โดรน |
| ปรุง | ปรุงทุกหม้อให้ (สูตรคุ้มสุด) | 👨‍🍳 เชฟอัตโนมัติ |
| ขาย | ขายทั้งหมด | 🧾 แคชเชียร์ |
| รวมดาว | รวมดาวทั้งหมด | 🧹 จัดช่องเก็บอัตโนมัติ (🪙1,000) |
| ปล่อยตัวซ้ำ | ปล่อยตัวซ้ำ (เก็บ 3 ตัวดีสุดของแต่ละชนิด) | (รวมใน 🧹) |
| ผสม | ผสมซ้ำคู่เดิม | 🔁 ผสมซ้ำอัตโนมัติ (🪙3,000) |
| สำรวจ | ส่งซ้ำ (เลือกลูกเรือให้) | 🔁 สำรวจซ้ำอัตโนมัติ (🪙1,500) |

ระบบอัตโนมัติใหม่ใช้ตัวจาก **ช่องเก็บเท่านั้น** (ไม่ดึงสัตว์ในฟาร์มไปผสม/สำรวจเอง) และไม่ส่งตัวสีพิเศษหรือตัวที่รวมดาวแล้ว มีสวิตช์เปิด/ปิดในแต่ละกล่อง ถ้าผสมอัตโนมัติแต่เงินไม่พอจะรอ ไม่ติดลบ

### 14.4 สิ่งที่ต้องดูตอนเล่น

1. ลากแล้วรู้สึกลื่นหรือเปล่า (ระยะเริ่มลาก 8 พิกเซล) บนจอทัชสกรีนเลื่อนหน้าโดยแตะที่ตัวสัตว์ไม่ได้ ต้องเลื่อนจากพื้นที่ว่าง ซึ่งอาจต้องปรับ
2. หน้าเดียวยาวไปไหม (ต้องเลื่อนเยอะเมื่อลากไกล) ถ้ายาวเกินให้พิจารณาวางกล่องเป็น 2 คอลัมน์บนจอกว้าง
3. ปุ่ม "ทั้งหมด" ครอบคลุมงานที่กดซ้ำจริงหรือยัง
4. ระบบอัตโนมัติเรื่องผสม/สำรวจทำให้เกมตื้นลงไหม (เพราะผู้เล่นไม่ต้องเลือกอะไร) หรือทำให้เล่นข้างจอได้ดีขึ้นอย่างเดียว

## 15. เลย์เอาต์หน้าจอเดียว (v0.4)

**ที่มา:** ผู้เล่นอยากให้ทุกอย่างอยู่ในหน้าเดียวโดยไม่ต้องเลื่อน (สอดคล้องกับการวางหน้าต่างไว้ข้างจอ)

### 15.1 โครงหน้าจอ

จอกว้าง (กว้างตั้งแต่ ~820 พิกเซล) จัดเป็น 3 คอลัมน์ พอดีหน้าต่างขนาดเล็กสุด **~900×680** โดยไม่ต้องเลื่อนหน้า:

```
┌─────────────────────────────────────────────────────────┐
│ 🪙เหรียญ  ~รายได้/นาที   🎒กระเป๋า 💦น้ำ 🌿  [อัปเกรด][สมุด][ทดสอบ] │
│ ข้อความล่าสุด + คำแนะนำบรรทัดเดียว                          │
├───────────────────┬─────────────────┬───────────────────┤
│ ฟาร์ม 4×3          │ 🍲 ครัว          │ 💞 โรงผสม          │
│ 🧺เก็บทั้งหมด 💦    │ กระเป๋า→หม้อ     │ 🧭 สำรวจ           │
│ สัตว์ที่เลือก       │ ตู้โชว์ + ช่องขาย  │                   │
├───────────────────┴─────────────────┴───────────────────┤
│ 🧺 ช่องเก็บสัตว์ (แถวของช่องเล็ก เลื่อนภายในกล่องได้)        │
└─────────────────────────────────────────────────────────┘
```

- **อัปเกรด / สมุดภาพ / ห้องทดสอบ** เปิดเป็นหน้าต่างซ้อนทับ (ปิดด้วยปุ่มหรือคลิกพื้นหลัง) ไม่ทำให้หน้าหลักยาวขึ้น ตำแหน่งเลื่อนในหน้าต่างไม่หายตอนเกมอัปเดต
- ช่องสัตว์ในช่องเก็บ/โรงผสม/ลูกเรือเป็นแบบเล็ก (อีโมจิ + ดาว + ไอคอนบทบาท) ชื่อดูได้จากการชี้ (tooltip) หรือเลือกแล้วดูแถบรายละเอียด
- ส่วนที่ยาวได้ (ตู้โชว์ ช่องเก็บ) เลื่อนภายในกล่อง ไม่ดันทั้งหน้า

### 15.2 ข้อจำกัดที่ยังมี

- **หน้าต่างแคบแนวตั้ง (~420 พิกเซล) ยังต้องเลื่อน** เพราะกล่องทั้งหมดไม่พอดีแนวตั้ง (ประมาณ 1,450 พิกเซล) ต้องเลือกว่าจะทำเลย์เอาต์แนวตั้งแยก (เช่น พับครัว/โรงผสม/สำรวจเป็นแถบ) หรือกำหนดให้หน้าต่างข้างจอเป็นแนวนอนอย่างเดียว
- ถ้าหน้าต่างเตี้ยกว่า ~680 พิกเซล ส่วนในกล่องจะเริ่มเลื่อน

### 15.3 คำถามสำหรับ Unity เวอร์ชันจริง

1. หน้าต่างข้างจอจริงควรเป็นแนวนอน (~900×680) หรือแนวตั้ง? ตัดสินใจก่อนเริ่มออกแบบ UI จริง เพราะเลย์เอาต์ต่างกันมาก
2. ถ้าเลือกแนวตั้ง ต้องพิจารณาโหมดแถบเล็ก (mini mode) ที่โชว์เฉพาะรายได้และสิ่งที่เสร็จแล้ว (ตามข้อ 8.3) และเปิดกล่องเต็มเมื่อคลิก

## 16. การตัดสินใจ: หน้าต่างแนวนอน และอัปเกรดแบ่งหมวด (v0.5)

### 16.1 หน้าต่างข้างจอ = แนวนอน (ยืนยันแล้ว)

ตอบคำถามข้อ 15.3: **หน้าต่างหลักเป็นแนวนอน ขนาดเล็กสุดราว 900×680** (3 คอลัมน์ตามข้อ 15.1) ผลที่ตามมา:

- เลิกพิจารณาเลย์เอาต์แนวตั้งแคบ ~420 พิกเซลสำหรับเวอร์ชันแรก (ที่เคยต้องเลื่อน)
- แถบเล็ก (mini mode, ข้อ 8.3) ยังจำเป็นสำหรับตอนวางไว้ขอบจอ แต่เป็นโหมดเสริม ไม่ใช่เลย์เอาต์หลัก
- ขนาดหน้าต่างต้องปรับได้ และจำตำแหน่ง/ขนาดล่าสุด

### 16.2 อัปเกรดแบ่งหมวด

หน้าต่างอัปเกรดแบ่งเป็น 5 หมวด แต่ละหมวดมีจุดแจ้งเตือน ● เมื่อมีอันที่ซื้อได้ในตอนนี้ (และจุดรวมที่ปุ่ม "อัปเกรด" ด้านบน):

| หมวด | อัปเกรด |
|---|---|
| 🧺 เก็บ | 🚁 โดรน · 🎒 กระเป๋า · 📦 กองหน้าช่อง |
| 🍲 ปรุง | 🍲 หม้อเพิ่ม · 🔥 ปรุงไวขึ้น · 👨‍🍳 เชฟอัตโนมัติ |
| 💰 ขาย | 🧁 ตู้โชว์ · 💰 ราคาขาย · 🧾 แคชเชียร์ · ⚡ แคชเชียร์ไวขึ้น |
| 💦 น้ำ | 💦 สปริงเกอร์ · ⛲ ปั๊มน้ำ · 🛢 ถังน้ำ |
| 🐾 สัตว์ | 🧹 จัดช่องเก็บอัตโนมัติ · 🔁 สำรวจซ้ำอัตโนมัติ · 🔁 ผสมซ้ำอัตโนมัติ · 🌿 ขยายช่องเก็บ (ใช้แก่นธรรมชาติ) |

หมวดเรียงตามลำดับของสายพานผลผลิต (เก็บ → ปรุง → ขาย) แล้วตามด้วยน้ำและสัตว์ ในแต่ละหมวดเรียง "ปลดล็อก" ก่อน "ปรับปรุงให้ดีขึ้น" ส่วนอันที่ต้องซื้ออันก่อนหน้าก่อน (เช่น ปั๊มน้ำต้องมีสปริงเกอร์) จะแสดงเป็นสีจางพร้อมเหตุผล

เมื่อมีอัปเกรดเพิ่ม ควรเพิ่มในหมวดที่มีอยู่ก่อน ถ้าหมวดใดเกิน ~6 อัน ค่อยพิจารณาแตกหมวดย่อย

## 17. สัตว์ที่ผสมหรือออกสำรวจ "ไม่อยู่ในฟาร์ม" (v0.6)

**ที่มา:** ในเวอร์ชันก่อนหน้า สัตว์ที่เข้าโรงผสมหรือออกสำรวจยังนั่งในช่องฟาร์ม/ช่องเก็บแบบจางๆ แล้วไปโผล่ซ้ำในกล่องโรงผสม ทำให้เห็นสัตว์ตัวเดียวสองที่และสับสนว่าตัวไหนทำอะไรอยู่ ผู้เล่นขอให้ตัวที่ผสมและตัวที่สำรวจ **ไม่อยู่ในหน้าฟาร์ม**

**กติกาใหม่ (แทนที่ข้อความเรื่อง "ล็อกตัว" ในข้อ 5.1 และ 5.2):**

1. เมื่อสัตว์ถูกวางลงโรงผสมหรือกล่องสำรวจ จะ **ถูกนำออกจากช่องฟาร์มหรือช่องเก็บทันที** ช่องฟาร์มที่ว่างลงวางสัตว์ตัวอื่นแทนได้ และช่องเก็บได้พื้นที่คืน
2. ระหว่างที่อยู่ในโรงผสม/ออกสำรวจ สัตว์ **ไม่ผลิต ไม่ทำบทบาท ไม่นับในช่องเก็บ** (ผู้เฝ้าฟาร์มที่ออกไปก็ไม่ช่วยเพิ่มเพดานออฟไลน์/ความจุ)
3. เมื่อเสร็จหรือยกเลิก สัตว์ **กลับที่เดิม** ถ้ามาจากช่องฟาร์มและช่องนั้นยังว่างจะกลับช่องเดิม ถ้าช่องนั้นมีตัวอื่นแล้วจะกลับไปที่ช่องเก็บ
4. สัตว์ที่กลับมาจะเข้าช่องเก็บได้ **แม้ช่องเก็บเต็ม** (ไม่มีวันถูกปล่อยทิ้งอัตโนมัติ) ช่องเก็บอาจเกินความจุชั่วคราว และไข่ใบใหม่จะรอจนกว่าจะมีที่ว่าง
5. ลากสัตว์ออกจากกล่องโรงผสม/สำรวจไปวางที่ฟาร์มหรือช่องเก็บ = ยกเลิกการเตรียม (ทำได้เฉพาะก่อนเริ่ม)
6. โหมดอัตโนมัติ (ผสมซ้ำ/สำรวจซ้ำ) ตรวจเงินค่าผสมก่อนหยิบสัตว์ออกมา ถ้าไม่พอจะไม่ขยับสัตว์เลย

**ผลต่อดีไซน์:** การดึงสัตว์จากฟาร์มไปผสมยังมีต้นทุน (ช่องนั้นหยุดผลิตจนกว่าจะเสร็จ) แต่ผู้เล่นเห็นต้นทุนนั้นชัดขึ้น เพราะช่องว่างจริงๆ และเลือกเอาตัวสำรองมาลงแทนได้ ซึ่งทำให้ช่องเก็บมีบทบาทเป็นตัวสำรองฟาร์มด้วย

**คำถามไว้ดูตอนเล่น:** ตัวที่ออกไปนานมาก (ผสมสัตว์ตำนาน 4 ชม. สำรวจ 12 ชม.) ผู้เล่นอยากให้ช่องที่ว่างอยู่เติมอัตโนมัติด้วยตัวสำรองหรือไม่

## 18. การ์ดข้อมูลสัตว์ (v0.7)

**ที่มา:** ผู้เล่นอยากให้แตะสัตว์ตัวไหนแล้ว "ขึ้นข้อมูลสัตว์ตัวนั้นเลย" เดิมข้อมูลอยู่ในแถบแยกใต้ฟาร์ม และถ้าเลือกสัตว์ค้างไว้แล้วแตะช่องฟาร์มอื่น เกมจะย้ายตัวที่เลือกไปแทนที่จะโชว์ข้อมูลตัวที่แตะ

**กติกา**
- แตะสัตว์ที่ไหนก็ได้ (ฟาร์ม ช่องเก็บ กล่องโรงผสม/สำรวจ) → การ์ดข้อมูลเด้งขึ้น **ข้างตัวนั้น** ทันที ตำแหน่งปรับให้อยู่ในจอเสมอ
- แตะสัตว์ตัวอื่นขณะการ์ดเปิด → การ์ดเปลี่ยนเป็นตัวใหม่ ไม่ย้ายสัตว์ (การย้ายทำด้วยการลาก หรือปุ่มในการ์ด)
- แตะช่องฟาร์ม **ว่าง** ขณะเลือกสัตว์จากช่องเก็บอยู่ → วางลงช่องนั้น (ทางลัด)
- ปิดการ์ดด้วยปุ่ม ✕, แตะที่ว่าง หรือกด Esc ขณะลากสัตว์การ์ดจะซ่อนชั่วคราว

**ข้อมูลในการ์ด:** ชื่อ · ระดับความหายาก · ดาว · สีพิเศษ · ที่อยู่ปัจจุบัน · ความสามารถทุกบทบาทพร้อม **ตัวเลขจริงของตัวนั้น** (รวมดาว/สีพิเศษ และโบนัสจากสัตว์ข้างเคียงถ้าอยู่ในฟาร์ม) · ผลผลิตและมูลค่าสำหรับผู้ผลิต · การกินน้ำ · สูตรที่ได้มา · ความคืบหน้ารวมดาว · ปุ่มจัดการ (ลงฟาร์ม/เก็บ/ใส่โรงผสม/ลูกเรือ/รวมดาว/ปล่อย)

ความสามารถที่ต้องอยู่ในช่องฟาร์มจึงจะทำงาน (ทุกบทบาทยกเว้นไม่มี) จะมีหมายเหตุกำกับเมื่อสัตว์ไม่ได้อยู่ในฟาร์ม

## 19. ตัดระบบน้ำ และเปลี่ยนอัปเกรดเป็นสายสกิล (v0.8)

### 19.1 ตัดระบบน้ำ (พักไว้ก่อน)

**ตัดออกจากโปรโตไทป์:** สปริงเกอร์ ปั๊มน้ำ ถังน้ำ แถบน้ำ และการกินน้ำของสัตว์ ผลิตกลับเป็นสูตรเดิมแบบไม่มีตัวคูณน้ำ (ความเร็ว = 1 ÷ ช่วงเวลาผลิต × ดาว/สีพิเศษ × (1 + โบนัสผู้หนุน)) **ข้อ 13.2 แถว "น้ำ" และข้อความเรื่องน้ำในข้อ 13.1 ใช้ไม่ได้แล้ว**

ที่พักไว้ ไม่ได้ทิ้ง: น้ำเคยทำหน้าที่เป็น "เพดาน" ให้สัตว์หายากไม่แรงเกินไป ถ้าสัตว์ตำนานเริ่มทำให้เงินเฟ้อเร็วเกินไปตอนทดสอบ ให้กลับมาพิจารณาระบบแบบนี้ (หรือเพดานแบบอื่น) อีกครั้ง

### 19.2 สายสกิลอัปเกรด

หน้าต่างอัปเกรดเปลี่ยนเป็น **4 เส้น เรียงซ้ายไปขวา** แต่ละเส้นต้องซื้อขั้นก่อนหน้า **อย่างน้อย 1 เลเวล** ถึงจะปลดล็อกขั้นถัดไป มีเส้นเชื่อมระหว่างขั้น (เส้นสว่างเมื่อขั้นก่อนหน้าซื้อแล้ว)

| เส้น | ขั้นที่ 1 | ขั้นที่ 2 | ขั้นที่ 3 | ขั้นที่ 4 |
|---|---|---|---|---|
| 🧺 เก็บ | 🚁 โดรน | 🎒 กระเป๋า | 📦 กองหน้าช่อง | |
| 🍲 ปรุง | 👨‍🍳 เชฟอัตโนมัติ | 🍲 หม้อเพิ่ม | 🔥 ปรุงไวขึ้น | |
| 💰 ขาย | 💰 ราคาขาย | 🧁 ตู้โชว์ | 🧾 แคชเชียร์ | ⚡ แคชเชียร์ไวขึ้น |
| 🐾 สัตว์ | 🌿 ขยายช่องเก็บ | 🧹 จัดช่องเก็บอัตโนมัติ | 🔁 สำรวจซ้ำอัตโนมัติ | 🔁 ผสมซ้ำอัตโนมัติ |

**หลักการเรียงลำดับ:** ขั้นแรกของแต่ละเส้นคือสิ่งที่คุ้มและจำเป็นที่สุดก่อน (เส้นเก็บ/ปรุงเริ่มที่ระบบอัตโนมัติเพราะนั่นคือจุดเปลี่ยนการเล่น เส้นขายเริ่มที่ราคาขายเพราะช่วยทั้งคนกดเองและระบบอัตโนมัติ เส้นสัตว์เริ่มที่ขยายช่องเก็บเพราะต้องใช้เร็ว) ขั้นท้ายๆ คือส่วนเสริม/อัตโนมัติราคาสูง

**แต่ละขั้นแสดง:** ไอคอน · ชื่อ · ผลสั้นๆ · แถบเลเวล · ราคา (🪙 หรือ 🌿) และสถานะ ปลดล็อกแล้วซื้อได้ (กรอบเขียวเรืองแสง) · ซื้อไม่ไหว · ล็อก (จาง เส้นประ) · เต็ม (เขียว ✓)

### 19.3 ผลต่อจังหวะเกม (จากบอททดสอบ ไม่ใช่ผู้เล่นจริง)

- โดรนตัวแรกยังซื้อได้ที่ ~4 นาที (เป็นขั้นแรกของเส้น)
- ระบบอัตโนมัติ "ครบชุด" (โดรน เชฟ แคชเชียร์) ช้าลงเป็น ~40 นาที เพราะแคชเชียร์อยู่ขั้นที่ 3 ของเส้นขาย ต้องผ่านราคาขายกับตู้โชว์ก่อน ถ้าผู้เล่นรู้สึกว่าช่วงต้นเกมต้องกดขายเองนานเกินไป ให้พิจารณาย้ายแคชเชียร์มาขั้นที่ 2 หรือลดราคาขั้นก่อนหน้า
- การล็อกตามลำดับทำให้ผู้เล่นมีทางเลือกน้อยลงในแต่ละเส้น แต่เลือกได้ว่าจะลงเส้นไหนก่อน ซึ่งเป็นการตัดสินใจหลักของระบบนี้

### 19.4 คำถามไว้ดูตอนเล่น

1. อ่านต้นสกิลแล้วรู้ทันทีไหมว่าควรซื้ออะไรต่อ
2. มีเส้นไหนที่ "ไม่มีเหตุผลต้องลง" หรือเส้นไหนที่ทุกคนลงก่อนเสมอ (ถ้ามี ต้องปรับให้สมดุล)
3. ควรมีแขนงแยก (ขั้นเดียวปลดล็อกสองขั้น) เพื่อให้เลือกได้มากขึ้นไหม

## 20. เพิ่มความลึกให้ การขาย · การปรุงอาหาร · การผสมพันธุ์ (v0.9)

**ที่มา:** ผู้เล่นขอให้โฟกัสสามระบบนี้ก่อน และบันทึกการศึกษาเกมอ้างอิง (`docs/References.md`) ชี้ว่าอัปเกรดแบบ +% ตื้น, ผลผลิตทุกชิ้นเหมือนกันไม่มีให้ลุ้น และระบบอัตโนมัติควรมีการตัดสินใจที่น่าสนใจ

### 20.1 การขาย

| กลไก | กติกา | ทำไม |
|---|---|---|
| **ตลาดอิ่ม** | ขายเมนูเดิมซ้ำ ราคาตกชิ้นละ 7% (ต่ำสุด −50%) แล้วค่อยๆ ฟื้น (~0.35 ต่อ 100 วินาที) แสดง "🔻ตลาดอิ่ม −x%" ที่แถวเมนู | ทำให้ "ขายทั้งหมดทีเดียว" ไม่ใช่ทางที่ดีที่สุดเสมอ และผลักให้ปรุงหลายเมนู (เสริมตัวคูณความหลากหลาย) แคชเชียร์เลือกขายเมนูที่ราคาตอนนี้ดีสุดเอง จึงกระจายเมนูอัตโนมัติ |
| **ออเดอร์พิเศษ** | ลูกค้าสั่งเมนูที่เคยปรุงแล้ว 2–4 จาน จ่าย **×2.5 + 🌿1** อยู่ 8 นาที (เวลาเกม) หมดเวลาไม่มีโทษ แล้วมีออเดอร์ใหม่ใน 30–45 วินาที ของที่ต้องใช้จะถูก **กันไว้** ไม่ถูกขายออก (ทั้งตอนกดเองและแคชเชียร์) แคชเชียร์ส่งออเดอร์ให้เองเมื่อครบ | ให้เป้าหมายระยะสั้นที่ผู้เล่นที่อยู่หน้าจอเลือกทำได้ โดยไม่บังคับ (ตามหลักไม่ลงโทษ) |
| **ลูกค้าต้องการ** | ของเดิม: 3 เมนู ×1.6 เปลี่ยนทุก 5 นาที (รวมสูตรลับที่ค้นพบแล้ว) | |

### 20.2 การปรุงอาหาร

- **สูตรลับ 9 สูตร:** ใช้ผลผลิตของ **สัตว์ชนิดเจาะจง** (ไม่ใช่แค่ตระกูล) ตัวคูณ ×2.6 ถึง ×6 สูงกว่าเมนูตระกูลทั่วไป (×1.4–×2.8) ต้องลองปรุงถึงจะค้นพบ
- **พรีวิวไม่เฉลย:** เมื่อใส่ของครบสูตรลับที่ยังไม่เคยพบ พรีวิวแสดง "✨ สูตรลับ! ปรุงเพื่อค้นพบ" พร้อมมูลค่า แต่ไม่บอกชื่อ (ผู้เล่นสังเกตได้ว่ามีอะไรพิเศษ)
- **สมุด:** หมวด "สูตรลับ" แสดงจำนวนชิ้นที่ต้องใช้ และใบ้ผลผลิตหนึ่งอย่างเมื่อเคยได้สัตว์ตัวนั้นแล้ว (เหมือนระบบใบ้สูตรผสมสัตว์)
- **เชื่อมกับการผสมพันธุ์:** สูตรลับส่วนใหญ่ต้องใช้ผลผลิตของสัตว์ที่ได้จากการผสม (ห่าน แกะขนทอง กวางทองคำ กินรี) ทำให้ผสมพันธุ์ → ปรุง → ขาย เป็นสายพานเดียวกันจริงๆ
- **เชฟฉลาดขึ้น:** ลองทุกชุดผสมจากของในกระเป๋า เลือกชุดที่ได้ราคาดีสุด **ตอนนี้** โดยคิดสูตรลับ ลูกค้าต้องการ และตลาดอิ่มรวมกัน (เดิมเลือกแค่ของแพงสุด)

| สูตรลับ | ใช้ | × |
|---|---|---|
| ไข่ตุ๋นนม · ไข่เค็มถั่ว · ซุปถั่วนม | ไข่ไก่+นมแกะ · ไข่เป็ด+ถั่วป่า · นมแกะ+ถั่วป่า | 2.6 |
| คัสตาร์ดทอง · ไข่สามสหาย | ไข่ห่าน+นมแกะทอง · ไข่ไก่+ไข่เป็ด+ไข่ห่าน | 3.4 |
| ซุปเห็ดทอง | นมอัลปาก้า+เห็ดทอง | 3.6 |
| สลัดทิพย์ | เห็ดทอง+ดอกไม้ทิพย์ | 4.5 |
| พายราชา | ไข่ห่าน+นมแกะทอง+เห็ดทอง | 5 |
| พายทิพย์ | ไข่ห่าน+นมแกะทอง+ดอกไม้ทิพย์ | 6 |

### 20.3 การผสมพันธุ์

- **สืบทอดสีพิเศษ:** ถ้าพ่อหรือแม่ตัวใดตัวหนึ่งเป็นสีพิเศษ ✨ โอกาสสีพิเศษของลูกเพิ่มจาก 5% เป็น 30% (บวกโบนัสผู้เร่งผสมเหมือนเดิม) แสดงเปอร์เซ็นต์ในกล่องโรงผสมก่อนกดเริ่ม ทำให้สัตว์สีพิเศษเป็นพ่อแม่พันธุ์ที่มีค่า ไม่ใช่แค่ตัวผลิตเร็วกว่า

### 20.4 ที่ยังไม่ทำ (ไว้ดูผลเล่นก่อน)

- ผสมพันธุ์: ช่องผสมหลายช่อง (ต้องรื้อโครงโรงผสม), ลูกผสมที่สืบ "คุณสมบัติ" จากพ่อแม่
- ปรุง: ผลผลิตกลายพันธุ์ (ไข่ทอง ฯลฯ) ตามข้อ 1 ของ `References.md`
- ขาย: ตัวเลือกนโยบายของแคชเชียร์ (ขายทันที / เก็บรอลูกค้าต้องการ)

### 20.5 คำถามไว้ดูตอนเล่น

1. ตลาดอิ่ม ทำให้ "ปรุงหลายเมนู" น่าสนใจขึ้นจริง หรือรู้สึกว่าโดนลงโทษที่ขายเยอะ (ถ้าเป็นอย่างหลัง ลดจาก 7% หรือให้ฟื้นเร็วขึ้น)
2. ออเดอร์ที่กันของไว้ทำให้งงไหมว่าทำไมขายเมนูนั้นไม่ได้ (มีป้าย 📋 กำกับแล้ว)
3. สูตรลับเจอเองโดยบังเอิญบ่อยแค่ไหน และผู้เล่นรู้สึก "อยากไล่หาให้ครบ" เหมือนสูตรผสมสัตว์ไหม
4. ผสมพันธุ์ที่มีสีพิเศษเป็นพ่อแม่ ทำให้ผู้เล่นตั้งใจเก็บตัวสีพิเศษไว้ไหม

## 21. จังหวะเร็วแบบ "คลิกรัว" และพักระบบอัปเกรด (v0.10)

**ที่มา:** ผู้เล่นรู้สึกว่าเข้าถึงสนุกช้า (กว่าจะผสมเสร็จ ทำอาหารเสร็จ ได้สำรวจครั้งแรก) เทียบกับเกม Roblox ที่คลิกไวมาก จึงขอให้ **ลบระบบอัปเกรดไว้ก่อน** แล้วปรับสามระบบนี้ใหม่ และแก้ปัญหาลากสัตว์จากฟาร์มไปสำรวจไม่ได้

### 21.1 พักระบบอัปเกรด (ข้อ 13.2, 14.3, 19)

- ซ่อนปุ่มอัปเกรด/ต้นสกิลออกจากเกม ค่าที่เคยมาจากอัปเกรดเป็น **ค่าคงที่**: กระเป๋า 30 · กองหน้าช่อง 5 · หม้อ 3 · ตู้โชว์ 30 · ช่องเก็บ 20 · ราคาขาย ×1 · ปรุงด้วยความเร็วพื้นฐาน
- **ไม่มีระบบอัตโนมัติชั่วคราว** (โดรน/เชฟ/แคชเชียร์/ผสมซ้ำ/สำรวจซ้ำอัตโนมัติ) ผู้เล่นกดเองทั้งวงจร โดยมีปุ่มรวม: 🧺 เก็บทั้งหมด → ปรุงทุกหม้อ → ขายทั้งหมด (3 คลิกต่อรอบ)
- แก่นธรรมชาติ 🌿 ไม่มีที่ใช้ตอนนี้ จึงซ่อนจากหน้าจอ (ยังสะสมในระบบ) ปุ่มปล่อยสัตว์เปลี่ยนเป็นได้ 🪙 อย่างเดียว
- โค้ดอัปเกรดยังอยู่ในไฟล์แต่ไม่มีทางเข้า เพื่อให้นำกลับมาได้ง่ายเมื่อจังหวะหลักสนุกแล้ว ตอนนำกลับมาต้องปรับตัวเลขอัตโนมัติให้เข้ากับจังหวะใหม่นี้

### 21.2 ตัวเลขจังหวะใหม่ (เร็วขึ้นราว 3–10 เท่า)

| | เดิม | ใหม่ |
|---|---|---|
| สัตว์ผลิต 1 ชิ้น (สามัญ → ตำนาน) | 8–16 วิ | **3–7 วิ** |
| ปรุงต่อชิ้น | 4 วิ (3 ชิ้น = 12 วิ) | **1.5 วิ** (3 ชิ้น = 4.5 วิ) |
| ผสมสัตว์ (ลูกระดับสามัญ → ตำนาน) | 20 วิ · 2 · 10 นาที · 1 ชม. · 4 ชม. | **4 วิ · 10 วิ · 25 วิ · 1 นาที · 2.5 นาที** |
| ค่าผสม (พิเศษ → ตำนาน) | 50 · 1.5K · 60K · 3M | 50 · **1.2K · 30K · 900K** |
| สำรวจ 5 โซน | 30 วิ · 30 น. · 2 ชม. · 6 ชม. · 12 ชม. | **8 วิ · 40 วิ · 100 วิ · 4 นาที · 8 นาที** |
| ลูกค้าต้องการเปลี่ยน | ทุก 5 นาที | ทุก **90 วิ** |
| ออเดอร์พิเศษ | หมดใน 8 นาที | หมดใน **3 นาที** ออเดอร์ถัดไปใน 10–15 วิ |
| ตลาดอิ่มฟื้น | ~100 วิ | ~**30 วิ** |

**ช่วงต้นเกม:** เริ่มด้วยสัตว์ 3 ตัวในฟาร์ม + **ไก่สำรองอีก 1 ตัวในช่องเก็บ** เพื่อให้ผสมหรือส่งสำรวจได้ทันที (ไม่ต้องรอได้สัตว์ตัวแรกก่อน)

### 21.3 แก้ลากสัตว์ไปสำรวจ

- ลากสัตว์ **จากฟาร์ม** ไปวางในกล่องสำรวจได้โดยตรง (เดิมต้องย้ายไปช่องเก็บก่อน) ช่องฟาร์มนั้นว่างระหว่างที่ออกไป และสัตว์กลับที่เดิมตามกติกาข้อ 17 ปุ่ม "เป็นลูกเรือ" ในการ์ดข้อมูลก็ใช้ได้กับสัตว์ในฟาร์มเช่นกัน
- ทดสอบด้วยเมาส์จริง: ลากเป็ดจากฟาร์ม → สำรวจ 8 วิ → กลับช่องเดิมพร้อมพบกระต่าย

### 21.4 ผลทดสอบด้วยบอท "ผู้เล่นกดเร็ว" (รอบละ ~8 วินาที ไม่ใช่ผู้เล่นจริง)

| เหตุการณ์ | เวลาในเกม |
|---|---|
| เริ่มผสมครั้งแรก / ปรุงจานแรก / ขายครั้งแรก | 0 วิ / ~16 วิ / ~24 วิ |
| สำรวจครั้งแรก | ~16 วิ |
| ซื้อช่องฟาร์ม 4 → 6 | 24 วิ → 40 วิ |
| สัตว์ระดับพิเศษ / หายาก / มหากาพย์ | 16 วิ / 2 นาที / ~27 นาที |
| ค้นพบสัตว์ 10 / 15 / 20 ชนิด | 2 นาที / 12 นาที / 38 นาที |

**ข้อสังเกต:** (1) ไม่มีอัปเกรดให้ใช้เงิน เงินจึงสะสมโดยไม่มีที่ใช้ (บอทมี 488K ตอนชั่วโมงแรก) จนกว่าจะถึงค่าผสมสัตว์ระดับสูง (2) จังหวะมหากาพย์ที่ ~27 นาทีขึ้นกับว่าได้พ่อแม่ระดับหายากครบหรือยัง ซึ่งเป็นผลของการสำรวจ ไม่ใช่เงิน (3) ระบบออฟไลน์ไม่มีความหมายในเวอร์ชันนี้ เพราะไม่มีอัตโนมัติ

### 21.5 คำถามไว้ดูตอนเล่น

1. เร็วพอไหม หรือยังรู้สึกรอ (ถ้ายังรอ ลดเวลาผสม/สำรวจต่อ หรือเพิ่มปุ่มรวม)
2. เร็วจนไม่มีจังหวะให้หายใจไหม โดยเฉพาะช่วงต้นที่ผลผลิตเต็มกองใน ~15 วินาที
3. วงจรเก็บ → ปรุง → ขาย 3 คลิก สนุกพอไหมเมื่อทำซ้ำเป็นสิบๆ รอบ (ถ้าเบื่อ นี่คือเหตุผลที่จะนำระบบอัตโนมัติกลับมา)
4. ตัวเลขช่วงกลางเกม (หายาก → มหากาพย์) ควรเร็วกว่านี้ไหม

## 22. ปรุงอาหารแบบ "โยนกี่ชิ้นก็ได้ มูลค่ารวมถึงขั้นไหนได้เมนูนั้น" (v0.11)

**ที่มา:** ผู้เล่นเสนอให้เปลี่ยนจากการเลือก 2–3 ชิ้นลงหม้อ เป็นระบบแบบ Roblox: โยนวัตถุดิบลงหม้อกี่ชิ้นก็ได้ภายใน 5 วินาที จำนวนจำกัดตามความจุกระเป๋า และ **ราคาวัตถุดิบรวมกันถึงเท่าไรได้เมนูนั้น** (ตัวอย่าง: รวม 10 ได้ไข่ต้ม, รวม 20 ได้ไข่คนหมูสับ)

**ข้อ 13.1, 20.2 (หม้อ 2–3 ชิ้น, ตัวคูณตระกูลคงที่, สูตรลับ 9 สูตร, เชฟเลือกชุดผสม) ถูกแทนที่ด้วยข้อนี้**

### 22.1 กติกา

1. หม้อมี 3 ใบ โยนของชิ้นแรกลงหม้อว่าง → หม้อเริ่มเดือด **5 วินาที** ตลอด 5 วินาทีนี้โยนเพิ่มได้ไม่จำกัดจนกว่าของในกระเป๋าจะหมด
2. เมื่อครบ 5 วินาที ได้ **เมนู 1 จาน** ตามมูลค่ารวมของวัตถุดิบ (T = ผลรวมมูลค่าวัตถุดิบ) ขั้นบันไดดูข้อ 22.2
3. **มูลค่าจาน = T × ตัวคูณของเมนู × (1 + 0.2 × (จำนวนตระกูลที่ต่างกัน − 1))** ตระกูลคือ ไข่ 🥚 / นม 🥛 / ของป่า 🌰 ใส่ครบ 3 ตระกูลได้ ×1.4
4. ถ้า T ต่ำกว่า 10 (ต่ำกว่าเมนูแรก) ของทั้งหมด **คืนเข้ากระเป๋า** ไม่เสียของ
5. ตัวเลือกปริมาณต่อครั้ง: **×1 / ×5 / ทั้งหมด** (ต่อชนิดวัตถุดิบ) และปุ่ม **โยนทั้งหมด** (ทุกชนิดในกระเป๋า) ลากวัตถุดิบไปวางที่หม้อก็ได้ และเลือกหม้อเป้าหมายโดยแตะแถวหม้อหรือวางลงหม้อนั้นโดยตรง
6. แต่ละหม้อแสดงสิ่งที่โยนลงไป มูลค่ารวม เมนูที่จะได้ตอนนี้ และ **อีกเท่าไรถึงจะได้เมนูขั้นถัดไป** เพื่อให้ผู้เล่นตัดสินใจโยนต่อได้ทันที

### 22.2 บันไดเมนู (ปรับตัวเลขได้ง่ายในตาราง `LADDER`)

| ขั้น | มูลค่ารวมถึง | เมนู | ตัวคูณ |
|---|---|---|---|
| 1 | 10 | 🥚 ไข่ต้ม | 1.2 |
| 2 | 20 | 🍳 ไข่คนนมสด | 1.3 |
| 3 | 40 | 🥞 ไข่เจียวฟู | 1.4 |
| 4 | 80 | 🍮 คัสตาร์ดนมไข่ | 1.5 |
| 5 | 160 | 🍄 ออมเล็ตเห็ด | 1.6 |
| 6 | 320 | 🍛 ข้าวผัดไข่ถั่ว | 1.7 |
| 7 | 640 | 🍲 ซุปครีมเห็ด | 1.8 |
| 8 | 1,280 | 🍰 ชีสเค้ก | 1.9 |
| 9 | 2,560 | 🥧 พายสามสหาย | 2.0 |
| 10 | 5,120 | 🥩 สเต็กเห็ดทอง | 2.1 |

หมายเหตุ: ชื่อเมนูปรับให้ตรงกับวัตถุดิบที่เรามี (ไข่ นม ของป่า) ไม่ใช้ "หมูสับ" ตามตัวอย่าง เพราะยังไม่มีสัตว์ที่ให้เนื้อ ถ้าอยากได้เมนูแบบนั้นต้องเพิ่มผลผลิตตระกูลใหม่ มูลค่าวัตถุดิบต่อชิ้นยังเป็น 6 / 24 / 96 / 384 / 1,536 ตามความหายากของสัตว์ผู้ผลิต

### 22.3 ผลต่อสิ่งอื่น

- **ตู้โชว์/ตลาดอิ่ม/ออเดอร์/ลูกค้าต้องการ** ใช้ "ขั้นของเมนู" เป็นชนิดเมนู (12 ชนิด) ลูกค้าต้องการสุ่มจากขั้นที่เคยทำได้ไม่เกินขั้นสูงสุด +2
- **สูตรลับ** (ข้อ 20.2) พักไว้ ไม่ทำงานในระบบนี้ เพราะผูกกับชุดวัตถุดิบ 2–3 ชิ้นที่เจาะจง ถ้าจะกลับมา ให้ทำเป็น "โบนัสเมื่อในหม้อมีวัตถุดิบชนิดนี้" แทน
- **เชฟอัตโนมัติ** (ยังพักไว้พร้อมระบบอัปเกรด) จะโยนทุกอย่างในกระเป๋าเมื่อมีของถึง 10 ชิ้นและมีหม้อว่าง
- **การสะสมเมนูในสมุด:** แสดงเมนู 12 ขั้นและมูลค่าที่ต้องถึง
- **ความเชื่อมกับสัตว์:** สัตว์ผู้ผลิตระดับสูงให้ของมูลค่าสูง ทำให้ขั้นเมนูสูงๆ ต้องพึ่งการผสมพันธุ์ (ยังเหมือนเดิม) แต่ตอนนี้ได้จากปริมาณ ไม่ใช่สูตรเจาะจง

### 22.4 ผลทดสอบด้วยบอท (ไม่ใช่ผู้เล่นจริง)

- ของน้อยกว่า 10 → คืนของครบ · 2 ไข่ (12) → ไข่ต้ม มูลค่า 14 · โยน 10 ไข่ + 10 นม + 2 ถั่วป่า (T=312) → ออมเล็ตเห็ด มูลค่า 699 (312 × 1.6 × 1.4)
- บอทกดเร็ว (รอบละ ~8 วิ): ปรุงจานแรก ~16 วิ · ขายครั้งแรก ~40 วิ · สัตว์ระดับหายาก 3 นาที · มหากาพย์ ~11 นาที (จากเดิม ~27 นาที เพราะจานใหญ่ขายได้เงินมากกว่า) · ครบ 12 ช่องฟาร์มที่ ~18 นาที
- เงินสะสมเกิน 1 ล้านที่ชั่วโมงแรก เพราะยังไม่มีอัปเกรดให้ใช้

### 22.5 คำถามไว้ดูตอนเล่น

1. การโยนภายใน 5 วิ รู้สึกเร็วและสนุกไหม หรือ 5 วิยาวไปสำหรับคนที่กดเร็ว
2. ขั้นบันไดคูณ 2 ต่อขั้น ทำให้อยากโยนเยอะขึ้นจริงหรือเปล่า (ตัวคูณเมนูเพิ่มช้ากว่ามูลค่า ถ้าอยากให้ "โยนเยอะคุ้มกว่ามาก" ต้องเพิ่มตัวคูณต่อขั้น)
3. หม้อ 3 ใบมีประโยชน์ไหม หรือใช้ใบเดียวพอ (ตอนนี้ใช้หลายใบเพื่อแยกเมนูคนละขั้นพร้อมกัน)
4. ควรกลับมาทำ "โบนัสจากวัตถุดิบเจาะจง" เพื่อให้ยังมีเหตุผลเลือกว่าจะโยนอะไร ไม่ใช่โยนทั้งหมดทุกครั้งไหม

บันทึกการค้นคว้าว่าอะไรควรบอกผู้เล่น อะไรควรปล่อยให้ค้นพบเอง พร้อมตรวจข้อความที่มีอยู่ในโปรโตไทป์ อยู่ที่ **`docs/TextGuidelines.md`** สรุปสั้น: ข้อความแบ่ง 4 ระดับ คือ **บอกเสมอ** (สถานะ ผลลัพธ์ เหตุผลที่กดไม่ได้ ต้นทุน) · **บอกครั้งเดียวตอนที่ต้องใช้** · **บอกเมื่อขอ** (การ์ดข้อมูล สมุด) · **ไม่บอก** (สูตรผสม เมนูไกลๆ) และโชว์ "ผลลัพธ์ตอนนี้" ไม่โชว์ "สูตร" ยังไม่ได้นำไปปรับในโปรโตไทป์ ต้องรอผู้เล่นตัดสินว่าจะทำข้อไหนก่อน

## 24. ทยอยเปิดกล่องและคำแนะนำครั้งเดียว (v0.12)

นำข้อเสนอ 4.1 และ 4.2 ใน `docs/TextGuidelines.md` ไปใช้ในโปรโตไทป์

### 24.1 ทยอยเปิดกล่อง

| ขั้น | เปิดเมื่อ | เปิดอะไร |
|---|---|---|
| 1 | เริ่มเกม | ฟาร์ม + ครัว (เก็บ → โยน → ขาย) |
| 2 | **ขายอาหารครบ 3 จาน** | โรงผสม + ช่องเก็บสัตว์ |
| 3 | **เริ่มผสมสัตว์ครั้งแรก** | สำรวจ |
| 4 | **ทำเมนูขั้น 3 (ไข่เจียวฟู, รวมถึง 40) ได้** | ออเดอร์ + ลูกค้าต้องการ (ตัวคูณ ×1.6 ใช้งานจากขั้นนี้) |

- กล่องที่ยังล็อกแสดงเป็นเงาจางเส้นประ พร้อมบอกเงื่อนไขและความคืบหน้า (เช่น 0/3) ตำแหน่งเดิมไม่ย้าย จึงยังอยู่ในหน้าเดียว
- ปลดล็อกแล้วไม่ล็อกกลับ มีข้อความ "🔓 ปลดล็อก ..." ในบันทึกเหตุการณ์
- ปุ่มในการ์ดข้อมูลสัตว์ที่เกี่ยวกับกล่องที่ล็อก (เก็บเข้าช่องเก็บ, ใส่โรงผสม, เป็นลูกเรือ, รวมดาว) จะไม่โผล่จนกว่าจะเปิด ปุ่ม "ปล่อย" ใช้ได้ตลอด
- **เปลี่ยนจุดเริ่มต้น:** เริ่มด้วยสัตว์ **4 ตัวในฟาร์ม** (ไก่ เป็ด แกะ ไก่) และช่องฟาร์มที่เปิดอยู่ 4 ช่อง (เดิมเป็น 3 ช่อง + ไก่สำรองในช่องเก็บ) เพราะช่องเก็บถูกล็อกในตอนแรก ช่องฟาร์มช่องที่ 5 ราคา 🪙220
- เซฟเก่าที่ยังไม่มีข้อมูลการปลดล็อกจะถูกคำนวณจากความคืบหน้าที่มี (ขายแล้วกี่จาน ผสมแล้วหรือยัง) ไม่ล็อกทับของเดิม
- แท็บทดสอบมีปุ่ม "ปลดล็อกทุกอย่าง" ไว้ให้ผู้ทดสอบข้าม

### 24.2 คำแนะนำครั้งเดียว

แถบคำแนะนำบรรทัดเดียวใต้หัวเกม แสดงทีละอัน **เมื่อถึงจังหวะที่ต้องใช้** หายเมื่อผู้เล่นทำสำเร็จ และไม่กลับมาอีก (บันทึกในเซฟ) บางอันมีเวลาหมดอายุเอง

| ลำดับ | แสดงเมื่อ | ข้อความ | หายเมื่อ |
|---|---|---|---|
| 1 | เริ่มเกม ยังไม่มีของ | รอสักครู่ สัตว์กำลังผลิตของ | มีของให้เก็บ |
| 2 | มีของกองหน้าช่อง | กด 🧺 เก็บทั้งหมด | เก็บครั้งแรก |
| 3 | มีของในกระเป๋า | กดไอคอนวัตถุดิบ หรือ "โยนทั้งหมด" ลงหม้อ (รวมมูลค่าถึง 10 ถึงจะได้อาหาร) | โยนครั้งแรก |
| 4 | มีอาหารในตู้โชว์ | กด "ขายทั้งหมด" | ขายครั้งแรก |
| 5 | ขายแล้ว | รอให้ของเต็มกระเป๋าแล้วโยนทีเดียว ยิ่งโยนเยอะ ยิ่งได้อาหารแพง | ได้เมนูครบ 2 ชนิด หรือผ่านไป 90 วิ |
| 6 | ขายครบ 2 จาน | แตะสัตว์เพื่อดูข้อมูล ลากเพื่อย้าย | แตะสัตว์ครั้งแรก หรือผ่านไป 60 วิ |
| 7 | โรงผสมเปิด ยังไม่เคยผสม | ผสมสัตว์: ลากสัตว์ 2 ตัวไปวางในกล่องโรงผสม แล้วกด "เริ่มผสม" | เริ่มผสมครั้งแรก |
| 8 | ผสมแล้วได้คู่ที่ **ไม่มีสูตร** ครั้งแรก | คู่นี้ไม่มีสูตร ได้พ่อหรือแม่แบบสุ่ม (สลับลำดับก็เหมือนเดิม) สูตรตายตัว ลองคู่อื่นดู | 20 วิ (ตอบข้อสงสัยเรื่อง "สูตรตายตัวไหม") |
| 9 | สำรวจเปิด ยังไม่เคยสำรวจ | สำรวจ: ลากสัตว์ไปวางในกล่องสำรวจ แล้วกด "ไป" | สำรวจครั้งแรก |
| 10 | มีออเดอร์แรก | ออเดอร์: ปรุงเมนูที่สั่ง แล้วกด "ส่ง" จ่ายแพงกว่าปกติ (ของที่ต้องใช้จะถูกกันไว้) | ส่งออเดอร์ครั้งแรก หรือผ่านไป 60 วิ |

- ปุ่ม **❔** ที่หัวเกมเปิดหน้าต่าง "วิธีเล่น" สรุปทุกกติกา กลับมาดูซ้ำได้เสมอ

### 24.3 ข้อความถาวรที่ตัดออก (ซ้ำกับสิ่งที่ UI บอกอยู่แล้ว)

"แตะสัตว์เพื่อดูข้อมูล · ลากเพื่อย้าย" (ติดถาวร) · "กระเป๋าว่าง (กด 🧺...)" · "ยังไม่มีอาหารในตู้โชว์" · ประโยคยาวในกล่องโรงผสม/สำรวจ (เหลือแค่ตอนยังไม่เคยใช้) · "(×1.6)" ข้างลูกค้าต้องการ (ย้ายไปอยู่ใน tooltip) · "ลากเมนูมาวางที่นี่เพื่อขาย" ย่อเป็น "ลากมาขาย" · ข้อความเกณฑ์ "รวมถึง 10 ได้ไข่ต้ม" ในหม้อว่าง แสดงเฉพาะก่อนทำเมนูแรก

### 24.4 ผลทดสอบ (ผู้เล่นจำลอง ไม่ใช่ผู้เล่นจริง)

ทดสอบด้วยการกดจริง: คำแนะนำเปลี่ยนตามลำดับถูกต้องตลอดช่วงเก็บ → โยน → ขาย → ผสม → สำรวจ · ปลดล็อกโรงผสมหลังขายครบ 3 จาน (~35 วินาทีในเกม) · ปลดล็อกสำรวจหลังเริ่มผสม · หน้าต่างวิธีเล่นเปิดได้ ไม่มี error

### 24.5 ที่ยังไม่ได้ทำ และคำถามไว้ดูตอนเล่น

- ยังไม่ได้ปรับ **ขนาดตัวอักษรไทย** ที่ 9–10 พิกเซล (TextGuidelines ข้อ 4.4)
- ค่าเกณฑ์ปลดล็อก (3 จาน / ผสมครั้งแรก / เมนูขั้น 3) เป็นค่าเดาของผม ต้องดูว่าเร็วหรือช้าไป
- ผู้เล่นรู้สึกว่าถูกจำกัดตอนกล่องล็อกไหม หรือรู้สึกว่าเกมง่ายขึ้นตอนเริ่ม
- คำแนะนำแต่ละอันอ่านทัน/อ่านแล้วทำตามไหม หรือข้าม (สังเกตว่าผู้เล่นทำอะไรก่อนที่คำแนะนำจะหายเอง)
- ข้อความที่ตัดไปแล้วมีอันไหนที่ผู้เล่นรู้สึกว่าขาดและถามหา (คือข้อความระดับ A ที่ตัดผิด)

## 25. ศึกษาด้วยการโคลนเกมฟาร์ม (v0.12)

ทำหน้าเล่นแยก `prototype/clone-garden.html` จำลองกลไกของเกมฟาร์มสไตล์ Roblox (ปลูก → เก็บ → ขาย ร้านรีสต็อก กลายพันธุ์ สัตว์เลี้ยง) เพื่อเรียนรู้ ไม่ใช่เพื่อวางขาย รายละเอียดและตารางเทียบกับเกมเราอยู่ที่ **`docs/CloneStudy.md`** ข้อค้นพบหลัก: เกมต้นแบบสร้างความตื่นเต้นจาก **ความผันผวน** (ขนาดและกลายพันธุ์สุ่ม) และ **ความขาดแคลน** (รีสต็อกตามเวลา) ส่วนเกมเราลึกด้านการเลือกและการค้นพบ แต่ผลผลิตคาดเดาได้ทั้งหมด ข้อเสนอแรกที่แนะนำคือ "ผลผลิตกลายพันธุ์และขนาดสุ่ม" ยังไม่ได้นำมาใส่ในเกมเรา

## 26. หม้อไม่บอกผลล่วงหน้า (v0.13)

**ที่มา:** ผู้เล่นขอให้ตอนโยนของลงหม้อ **ไม่บอกว่าจะได้เมนูอะไร และไม่บอกว่าอีกเท่าไหร่จะได้เมนูไหน** ให้เป็นการลองแล้วค้นพบเอง (ตรงกับหลักข้อ "ไม่บอก ให้ค้นพบ" ใน `TextGuidelines.md`)

**แทนที่ข้อ 22.1 ข้อ 6 และข้อ 22.2 (ตารางเกณฑ์) ในส่วนที่เป็นการแสดงผล** กติกาการคำนวณเมนูไม่เปลี่ยน (ยังเป็นบันไดตามมูลค่ารวม) เปลี่ยนเฉพาะสิ่งที่ผู้เล่นเห็น

| ที่เดิมแสดง | ตอนนี้ |
|---|---|
| ในหม้อ: "รวม 36 → ไข่คนนมสด · อีก 4 ได้ไข่เจียวฟู" | **แสดงเฉพาะของที่โยนลงไปและเวลาที่เหลือ** (เช่น 🥚×7 🥛×5 · 0:05) ไม่มีมูลค่ารวม ชื่อเมนู หรือส่วนต่างถึงขั้นถัดไป |
| หม้อว่าง: "รวมถึง 10 ได้ ไข่ต้ม" | แสดงแค่ "หม้อ 1: ว่าง" |
| คำแนะนำ: "(รวมมูลค่าถึง 10 ถึงจะได้อาหาร)" | "แล้วรอดูว่าได้อะไร" (ยังบอกกติกา **ยิ่งโยนเยอะยิ่งแพง** เพราะเป็นหลักการ ไม่ใช่ตัวเลข) |
| บันทึกเมื่อของน้อยเกิน: "ต้องรวมถึง 10" | "ของน้อยเกินไป ยังไม่ได้อาหาร คืนของเข้ากระเป๋า" |
| สมุด: เมนูที่ยังไม่พบแสดง "❓ ≥80" | แสดงแค่ ❓ เมนูที่พบแล้วแสดงชื่อ ไม่แสดงเกณฑ์ |
| ปลดล็อกออเดอร์: "ทำเมนูไข่เจียวฟู (รวมถึง 40)" | **เปลี่ยนเงื่อนไขเป็น "ค้นพบเมนูครบ 3 ชนิด (0/3)"** (เดิมคือค้นพบเมนูขั้นที่ 3) |

**ผู้เล่นรู้ผลได้จากไหน:** หลังหม้อครบ 5 วินาที จานที่ได้ไปอยู่ในตู้โชว์พร้อมชื่อและราคา มีบันทึก "ค้นพบเมนู ..." เมื่อได้เมนูใหม่ และสมุดบันทึกเมนูที่เคยทำ ความคืบหน้าที่ผู้เล่นเห็นได้จึงเป็น ราคาจานที่ได้เทียบกับที่โยนไป

**ความเสี่ยงที่ต้องดูตอนเล่น:**
1. ผู้เล่นใหม่อาจไม่รู้ว่าควรโยนเท่าไหร่ จึงโยนทั้งหมดทุกครั้ง (ซึ่งเป็นกลยุทธ์ที่ดีอยู่แล้ว) หรือโยนน้อยจนได้ของคืนซ้ำๆ แล้วรู้สึกว่าเกมไม่ตอบสนอง คำแนะนำรอบแรกและข้อความ "ยังไม่ได้อาหาร" ต้องชัดพอ
2. ถ้าผู้เล่นอยาก "เล็งเมนู" (เช่น สำหรับออเดอร์) จะทำได้ยากขึ้นเพราะไม่รู้ว่าต้องโยนเท่าไหร่ ให้ดูว่าต้องเพิ่มคำใบ้บางส่วนไหม เช่น หลังค้นพบเมนูแล้ว ให้ **จำปริมาณที่เคยโยนได้เมนูนั้น** ไว้ในสมุดเป็นใบ้
3. ถ้าผู้เล่นรู้สึกว่า "สุ่มเกินไป" ทั้งที่จริงเป็นสูตรตายตัว ควรมีข้อความที่ยืนยันว่ายิ่งโยนเยอะยิ่งแพงเสมอ (มีอยู่ในคำแนะนำและหน้าวิธีเล่น)
